**Daggerfall × ドラクエ 構想メモ**

*追記セッション：御者・馬車・世界カスタム設定編*

「めんどくさいけど自由度が半端なく高いドラクエ」というコンセプトのもと、今回は「移動」まわりのシステム——馬車の所有と耐久度、御者・馬丁という専門職、そしてそれらを支える「世界作成時のカスタム設定」について議論した。既存メモの「話題ウィンドウ／覚える」「影響度（隠しパラメータ）」の作法を、新しい要素にも一貫して適用する方向で発展させている。

# 1. マンティコア関所：会話サンプルlog

「はなす」システムの実例として、関所突破シーンの会話フローを検討した。

**番人「**知っての通り、この先はマンティコアの生息地域だ。この先は通れんよ**」**

→ ここで「マンティコア」「この先」が話題ウィンドウに開示される。「覚える」を実行しないと以降の会話に反映されない。

**プレイヤー（尋ねる）「**マンティコア**」**

**番人「**マンティコアについて聞くなんてお前新人か？ 悪いことは言わない。迂回路を通れ**」**

→ 知識の有無そのものが会話内でキャラクターに読まれる。「新人」判定は影響度とは別軸の「地域住民としての評判・顔見知り度」として機能しうる。

**プレイヤー（尋ねる）「**迂回路**」**

**番人「**比較的マンティコアがいない道だ。10日もあれば通過できるだろ**」**

→「比較的」という言い回しが情報の不完全さを示唆。番人自身も伝聞・経験則で喋っている可能性。10日はあくまで最短見積もりで、道中の「所要時間が増えるイベント」次第で伸びうる。

**プレイヤー（尋ねる：嫌いなもの → マンティコア）「**（生態・弱点、あるいは番人個人の感情を尋ねる）**」**

語順（「マンティコア＋嫌いなもの」か「嫌いなもの＋マンティコア」か）で意味合いが変わりうる、という着眼点が出た。前者は生態情報（弱点）を尋ねる実用的な質問、後者は番人個人の感情・トラウマに触れる質問、という読み分けが可能。実装上は「起点となる単語（最初に選んだ方）が文脈を決める」ルールが、コストと表現力のバランスとして妥当と思われる。

## 関所突破シーンで生まれる選択肢の整理

| **行動** | **内容・帰結** |
| --- | --- |
| 引き返す | 素直に迂回路へ |
| 通行証・依頼書を見せる | 討伐依頼中や特別許可があれば通行可 |
| 賄賂を渡す | 影響度でも忠誠度でもない、番人個人の裁量に依存する交渉軸 |
| 無理やり突破する | 戦闘、または番人が加勢を呼ぶイベントへ発展 |

## 1-1. 「たずねる」コマンド：場所・存在を訊く

セクション1の「はなす」画面の行動ウィンドウに置く「たずねる」コマンドの一種として、**「ここは どこ？」「トリポリは どこ？」「シレンツィアを 知っている？」** のような、場所や存在そのものを尋ねる質問形式を追加する。

### 会話サンプルlog：新しい土地に着いた直後

```
ʕ•͡ω•ʔ 新しい土地に来たぞ。あ、町の人がいる。聞いてみよう
(●´ω｀●)
　↓
ʕ•͡ω•ʔ たずねる → ここ → どこ？
(●´ω｀●) ようこそ、旅の人。ここはトリポリです
```

→ まず対象の単語（「ここ」）を選び、次に聞き方（「どこ？」）を選ぶ、**名詞先行**の順序で統一する。「はなす → あいさつ → こんにちは」（後述）が「コマンド種別 → 話題カテゴリ → 定型文」という順であるのに対し、「たずねる」は対象の単語が話題ウィンドウの開示語彙そのままなので、一段目は常に話題ウィンドウの単語一覧から選ぶ形になる。返答に出てきた「トリポリ」は話題ウィンドウに開示され、「覚える」を実行しないと以降の会話に反映されない（セクション1の作法どおり）。

（実プレイでは「ここ→どこ？」と「どこ？→ここ」のどちらから選ぶべきか迷う、という声が出た。日本語の会話感覚では疑問詞が先に立つほうが自然に感じられる一方、UIの階層としては話題ウィンドウの単語を起点にする方が既存の設計と一貫するため、名詞（対象）→聞き方、の順で統一する。）

### 質問の型

| 型 | 例 | 返答の内容 |
| --- | --- | --- |
| 現在地を訊く | 「ここは どこ？」 | 町名・国・地域。街道上なら「〇〇と△△のあいだの街道だ」、迷宮内なら「知らん。お前こそ誰だ」 |
| 場所を探す | 「トリポリは どこ？」 | 知っていれば方角・所要日数・経路の断片。知らなければ「聞いたこともねえ」 |
| 存在を訊く | 「シレンツィアを 知っている？」 | 人物・物事についての知識。相手の立場・関係によって反応が変わる |
| 定義を訊く | 「マンティコアは 何？」 | 生態・見た目など百科事典的な説明。「知っている？」が関係性込みの反応（警戒される等）を引き出すのに向くのに対し、「何？」は純粋な知識の中身を引き出すのに向く |

### 誤操作から見つかった落とし穴：「誰？」の主語の曖昧さ

「たずねる → 誰？」を「NPCの素性を尋ねる」つもりで選んだところ、「私」を選んでしまい「（NPCから見て）私は何者か」という質問として処理され、「おかわいそうに、記憶喪失なのですか？」と返ってきた、という誤操作が実プレイで起きた。

これは「どこ？」型の取り違え（「ここ」と「トリポリ」のどちらを選んでも文法的に破綻しないため、間違えても一応成立してしまう）とは異なり、**質問の主体がひっくり返る**という質の違う誤爆である。対象が「人物」の場合、選ぶ単語が「私」なのか「あなた」なのか「NPCの名前」なのかで意味が全く変わる。

この誤爆は削るよりも仕様として採用したほうが得だと考えられる。「たずねる → 誰？」の選択肢に「私」と「あなた」を両方置き、

- 「誰？→あなた」：NPCの素性を尋ねる（意図通りの質問）
- 「誰？→私」：NPCがプレイヤーをどう認識しているか尋ねる。プレイヤー自身の評判・噂・見た目の印象などを引き出す、ジョーク寄りのコマンドとして生かす

という two-way の設計にする。

### 多段階の掘り下げと「知らない」の3段階

「たずねる」は対象を選んだ後、さらに属性を挟んで深掘りできる。

```
ʕ•͡ω•ʔ たずねる → マンティコア → 何？
(*ﾟ∀ﾟ) マンティコアも知らないのか？ もしかしてお前、新米か？ マンティコアは人食いの凶暴な獅子だ
　↓
ʕ•͡ω•ʔ たずねる → マンティコア → 弱点 → 何？
(*ﾟ∀ﾟ) マンティコアの弱点については全くわかっていない。だが、★★騎士団の団長なら… いや、お前に言っても無駄か…
```

→ `対象 → 属性 → 聞き方`（例：`マンティコア → 弱点 → 何？`）という4階層目の掘り下げが自然に発生する。属性（「弱点」「生態」等）も話題ウィンドウの語彙として扱えば、既存のUI階層をそのまま延長できる。

この例では「知らない」の返答に段階があることも見えてきた。

| 段階 | 例 | 特徴 |
| --- | --- | --- |
| 完全に知らない、それで終わり | 「知らんな」 | 手がかりなし |
| 知らないが、誰に聞けばいいか知っている | 「★★騎士団の団長なら…」 | 知識グラフ上の「詳しい人物ノード」へのポインタを返す。ノード自体は空でも、そのノードに詳しい人物への参照エッジだけは持っている状態 |
| 知っているが話さない（隠している） | セクション1の番人の警戒対応と地続き | 影響度・目星で見抜ける余地を残す |

「誰に聞けばいいか知っている」パターンは、話題ウィンドウに新しい固有名詞（「★★騎士団」）を開示する形になるため、「覚える」を通じて次の探索先が自然に提示される小さなクエスト誘導として機能する。

さらに、「弱点については全くわかっていない。だが……いや、お前に言っても無駄か…」のような**言い淀み**は、ただの「知らない」の言い回しバリエーションではなく、番人側が何か言いかけて止めた、隠し情報がある可能性を匂わせる表現として扱える。ここから「食い下がる」選択肢（もう一押し尋ねる、影響度が高ければ聞き出せる、等）が生まれる余地がある。

### 知識のポインタを辿った先にある社会的障壁

「弱点は★★騎士団の団長なら知っているかも」というポインタを実際に辿ってみた例が出た。

```
ʕ•͡ω•ʔ たずねる → ★★騎士団団長 → どこ
(*ﾟ∀ﾟ) 彼女は◇◇砦に赴任しているが、お前のようなやつにはお会いにならないだろうな
```

→ 「どこ？」で**所在**は素直に判明する（`location` エッジは辿れる）が、「お前のようなやつにはお会いにならないだろうな」で**面会できるかどうか**は別問題として拒まれる。目的地に着けば即クリアではなく、もう一段階「謁見の可否」という社会的な障壁が挟まる。この「お前のようなやつには」は、セクション1・1-1で繰り返し出てきた「新人か？」判定と同じ、影響度とは別軸の素性・評判によって門前払いされるパターンである。

つまり「たずねる」で辿る情報網は、次のような多段階の経路になりうる。

```
マンティコアの弱点を知りたい
  ↓（たずねる：知らない、誰に聞けばいいかは知っている）
★★騎士団団長なら知っているらしい
  ↓（たずねる：どこ？）
◇◇砦にいる。ただし会えるかは別問題
  ↓（？）
謁見のための条件（紹介状・実績・討伐依頼の達成など）が必要になりそう
```

謁見条件の具体案として、**衛兵の依頼を一定量こなすと団長への紹介状を書いてもらえる**、というルートが挙がった。これは既存メモの「実務・実績を第三者が評価する」という設計思想（プロ値の契約書、栄達ルートの因果構造、セクション10-3-2）と地続きで、「たずねる」で見つけた情報の入手経路そのものが、地道な実績の積み上げというサブクエスト構造を生む形になる。衛兵の依頼者（発注側）と紹介状の発行者（団長）が別人格である点も、既存の「第三者が評価・保証する」仕組み（プロ値の雇用契約書、公認資格の書類、セクション10-3の「妖魔に対する鉄槌」の識別判定等）と一貫している。

紹介状ルート以外にも、噂・実績・影響度などいくつかの経路が考えられ、経路によって信頼性や難易度が変わる、という設計に広げられそうである（ギルド経由の雇用契約書が信頼できる一方、酒場スカウトが自己申告のみ、というセクション2-4の対比と同じ構造）。

### NPCの個性差：新人判定のタイミング

「新人か？」という定型的なツッコミも、言うタイミングでキャラクターの人当たりの良さが変わることが分かった。

- **警戒先行型**（セクション1の関所番人）：質問した時点で「新人扱い」→ 情報を出し渋る、迂回路を勧めるなど、警戒が先に立つ
- **世話焼き先行型**（別の番人の例）：質問には普通に答えてから「もしかしてお前、新米か？」と後から茶化す。情報開示を渋らない、面倒見の良いタイプ

同じ「新米か？」という定型ツッコミでも、情報開示の前に言うか後に言うかでNPCの人当たりの良さが変わる。この違いをNPCごとの軽いフラグ（例：`newbieJudgment: "before" / "after" / "none"`）として持たせると、キャラの個性づけに使えそうである。

### 設計のポイント

- **答えはNPCの知識依存**：旅人は「東へ十日ほどだ」と言うが、農民は「聞いたこともねえ」。知識の範囲と質は人によって違う
- **不確かさを言い回しで出す**：関所の番人の「比較的マンティコアがいない道だ」（セクション1）と同じ作法で、「たしか東のほうだったと思うが……」のような曖昧な答えを許す。伝聞・経験則で喋っている感じを出す
  - 相手の知識ノードに信頼度（確実／うろ覚え／伝聞）を持たせれば、返答の言い回しを変えられる
- **答えは「覚える」の対象**：地名・方角・経路は話題ウィンドウ／知識グラフに入れられる。聞いたことがつながって地図になっていく
- **地図がなくても旅が成立する**：「トリポリは どこ？」の答えは、相手が知っている経路の断片（「〇〇まで行けば、あとは誰かに訊け」）をつなぐ形にする。断片を乗り継いで目的地に着く
- **「シレンツィアを知っている？」型は素性を読まれる**：質問の内容自体が相手にこちらの素性を教えてしまう（セクション1の「新人か？」判定と同じ構造）
  - 知っていて好意的 → 詳しく教えてくれる
  - 知っていて警戒 → 「なぜ、そんなことを聞く？」と逆に探られる
  - 知らない → 「知らんな」。本当に知らないのか隠しているのかは、影響度・目星で見抜ける可能性がある

### 世界設定との連動

- `eraPreset` が古いほど地理知識は乏しく、遠い土地は伝説・噂レベル。`narrowpa` なら地図屋がいて、正確な距離まで教えてくれる（識字率・書類読解、旅の摩擦の既定値と同じ軸）
- ギルド構成（酒場＋冒険者の統合など）が違えば、「土地の事情に詳しい人」がいる場所も変わる（酒場の主人／ギルドの受付／巡礼路の案内人）
- 吟遊詩人（10-1）経由なら、遠い土地の情報が歌として入ってくる。ただし誇張・改変の可能性つき

### UI案：覚えたフレーズを「カード」として扱う

話題ウィンドウで「覚える」を実行した単語を、単なるリスト項目ではなく**カード**として持ち歩き、「たずねる」の際にカードを並べて質問文を組み立てる、というUI案が出た。

- 話題ウィンドウの語彙が「持ち物」として可視化される、インベントリ的なメタファーになる
- 「マンティコア」カード＋「弱点」カード＋「？」カードを並べる、のように質問の構成要素を視覚的に組み立てられる
- セクション1で出た語順問題（「マンティコア＋嫌いなもの」か「嫌いなもの＋マンティコア」か）も、**カードを並べる順番そのものが操作として意味を持つ**ため、階層メニューを潜るより直感的に解決できる可能性がある。「たずねる → 対象 → 属性 → 聞き方」という抽象的な階層構造を、目に見えるカードの配置に置き換えるイメージ
- 「知らない単語のカードは手元に無い」という状態が、そのまま「話題ウィンドウにまだ開示されていない」をそのまま表現できる（開示されていない情報は物理的にカードとして存在しない）
- 「誰？→私／あなた」のような主語の取り違え（1-1既出）も、「私」カードと「あなた」カードを別々に持たせることで、選択の意図がUI上ではっきりする

この案は「たずねる」の階層メニュー構造（対象→属性→聞き方）と対立するものではなく、**同じ階層構造を見た目としてカードで表現する**具体化案として位置づけられる。

### 実装メモ

- 知識グラフに `location` / `person` / `thing` のノード種別があれば、「たずねる」の返答は「相手が持っているノードへのエッジ」を辿るだけで作れる
- 「ここ」「どこ？」のような選択肢は、話題ウィンドウの単語選択と同じUIで扱える（起点となる単語が文脈を決めるルール、セクション1参照）
- 属性（「弱点」等）も話題ウィンドウの語彙として扱うことで、`対象 → 属性 → 聞き方` の多階層掘り下げを既存UIの延長で実現できる
- 「詳しい人物ノードへの参照エッジ」を持たせることで、「知らない」の返答から次の探索先（クエスト誘導）を自然に生成できる

### 未決

- 現在地を訊いても「答えてもらえない」場面（警戒されている、言葉が通じない）をどこまで作るか
- 知識ノードの信頼度（確実／うろ覚え／伝聞）を、話題ウィンドウ側にも表示するか
- 間違った情報（うろ覚え・嘘）を「覚える」してしまった場合の訂正の仕組み
- 「誰？→私」の評判照会が、実際にどんな情報源（噂・見た目・影響度）を参照して返答するかの設計
- 言い淀み演出から「食い下がる」選択肢を出す条件（影響度の閾値、繰り返し訪問など）
- 「謁見の可否」のような社会的障壁を突破する経路（紹介状・実績・影響度等）を、どこまで汎用のサブクエストパターンとして定式化するか
- カードUI案を階層メニュー案とどちらで実装するか、あるいは両方を状況に応じて出し分けるか

# 2. 馬車・御者・馬丁システム

## 2-1. 馬車の所有

- Daggerfall本家には「徒歩・馬・船」の移動手段選択、宿屋か野宿かの選択はあったが、「乗り合い馬車」「キャラバンへの便乗」のような社会的・経済的な移動オプションの多層性は本家にはなかった発明部分。

- 維持コスト：餌代・厩舎代がかかる。宿屋のグレード選択と対になる発想。

- 宿屋（高コスト・高品質）／野宿（無料・不安定）／自前の馬車（初期投資後は安定）の三択構造。

- 積載量の拡張、荷物を多く運べる実用面。

## 2-2. 耐久度（マスクデータ）

耐久度システムはプレイヤーに嫌われやすい典型パターンがある一方、受け入れられやすい設計の条件も存在する。

| **嫌われるパターン** | **受け入れられやすい設計** |
| --- | --- |
| 修理コストが理不尽に高い | 壊れそうな予兆がある（メーターやNPCの忠告） |
| 壊れるタイミングが完全ランダム | 壊れても即詰みにならず代替手段がある |
| 壊れた瞬間に詰む | プレイヤーの選択の結果として壊れる（自業自得感） |

→ 結論として、耐久度は影響度と同じ「隠しパラメータ」として扱い、目星や知識判定で見抜く／専門家に相談するという既存の作法を横展開する形に着地。

## 2-3. 馬丁・御者という専門職

|  | **馬丁** | **御者** |
| --- | --- | --- |
| 立ち位置 | その場限りの相談相手（街・厩舎にいる） | 同行する専門家（旅に同行し常時アクセス可） |
| 機能 | 尋ねれば状態を教えてくれる／目星で自力確認も可 | 自発的に「そろそろ修理を」と警告してくれる |
| コスト | 相談料（都度） | 雇用の給金（継続コスト） |

- 御者を雇うことは「耐久度管理のストレスを金で解消する」というプレイヤー側の意思決定として機能する。雇わない場合は目星＋馬丁への相談という無料の代替ルートが残る。

- 御者にも影響度が及びうる：腕は良いが忠誠心はない御者／腕は並だが信頼できる御者、というキャラクター性の対比。

- 危険地帯（マンティコア生息域）を前に、影響度が低い御者は尻込みする可能性。

## 2-4. プロフェッショナル値

御者・馬丁の「腕前」を示す値。高いほど的確なタイミング・精度で警告してくれるが、その分雇用コストが高い。

- プロ値と給金が単純な線形だと「金を積むほど安心」という単調なゲームになりがちなため、一定水準を超えると給金が急に跳ね上がる（一流は稀少で高額）設計が望ましいのではという議論。

- この仕組みは御者・馬丁に限らず、鑑定士・交渉代行人など「専門家に相談する」あらゆる場面に横展開できる汎用フレームになりうる。

### プロフェッショナル値をどう知るか

| **手段** | **特徴** |
| --- | --- |
| 実績で分かる | 雇って数日経ってから経験的に判明。ギャンブル性が高い |
| 紹介制度（ギルド・口入れ屋） | 質はある程度保証されるが紹介料が乗る |
| 評判・噂ベース | 話題ウィンドウ経由。「覚える」を怠ると良い人材を見逃す |
| 雇用契約書に明記 | ギルド等の第三者機関が査定・保証する体裁 |

最終的に「雇用契約の書類にプロフェッショナル値が記載されている」という案に着地。これは「隠しパラメータを推測する」のではなく「契約書という媒体にもとから数値として明記されている」という扱いになる。

- ギルド経由の雇用は査定済みの信頼できる書類、酒場スカウトは書類なし・自己申告のみ、という経路による差別化が可能。

- 偽造・改竄の余地を残せば、「この数値は本当か」を疑う形で目星や知識判定が復活する。

## 2-5. 成長システム：スキルベース＋休息必須レベル制

これまでのセクションでは移動・会話・隠しパラメータまわりの議論が中心で、キャラクターの「成長」そのものにはほとんど触れていなかった。Daggerfall本家の成長システムを参照点に、方向性を検討した。

### Daggerfall本家の成長システムの整理

- **キャラメイクは質問診断制**：クラスを直接選ぶのではなく、一連の性格診断のような質問に答えることでクラスが決まる（手動でカスタムクラスを組む方式もある）
- **Learn by Doing**：経験値をモンスター討伐で稼ぐ古典的な方式ではなく、**スキルを使うことでそのスキルが上がる**（剣を振れば剣術が上がる、忍び歩けば隠密が上がる）
- **レベルアップは間接的**：主要スキル（Primary Skills）の合計値が閾値に達すると自動的にレベルが上がり、HPや属性ボーナスが決まる。プレイヤーが能動的に「レベルアップ」を選ぶのではなく、プレイの結果として後からついてくる
- **属性（Attributes）**：Strength・Intelligence・Agility等の基本値があり、レベルアップ時に関連スキルの伸びに応じて上昇する
- **睡眠が必須**：レベルアップの反映には「休む（sleep/rest）」という行為が必要で、寝るまでは保留状態になる

### 二層構造の採用方針

「スキルベース（Learn by Doing）」と「レベル制＋休息必須」のどちらにするか検討した結果、**Daggerfall本家と同じ二層構造をそのまま採用する**方針とした。両者は対立する選択肢ではなく、実質的にレベル制がスキルベースの上位互換にあたる関係になっている。

1. **スキルは使うことで地道に育つ**（Learn by Doing）：透明性が高く、プレイスタイルの多様性をそのまま許容する
2. **レベルアップ（HP等の総合的な伸び）は休息というアクションを介してのみ確定する**：スキルが伸びていても、休息するまではレベルに反映されない保留状態が続く

この二層構造には、既存メモの他セクションとの接点がいくつかある。

- **セクション3の書類読解スキルとの接続**：Learn by Doingの透明さは、「情報収集そのものがキャラビルドの一部になる」という設計思想と直結する。書類読解・目星・妖魔学のような隠しパラメータ対応スキルを実際に使う（＝判定に挑む）ことでスキル自体が育つようにすれば、「隠しパラメータを見抜く力を育てる」というテーマと二重に噛み合う
- **セクション2-1の宿屋・野宿・馬車との接続**：「休息必須」の縛りは、移動と休息の経済にそのまま絡む。レベルを上げたいなら安全な場所で休まねばならない、という制約が、危険地帯での踏破判断（マンティコア関所を無理に突破するか、迂回して休息地を確保するか）に緊張感を足す
- **「めんどくさいけど自由度が高い」という本編のコンセプトとの一貫性**：Learn by Doingはまさに「めんどくさいが自由」を体現する成長方式であり、既存の作風と齟齬がない

この設計だと、「危険な旅の途中でスキルは伸びているが、レベル反映は安全な宿に着くまでお預け」という状態が生まれる。マンティコア関所を前にして「まだ休めていないから見た目より弱いかもしれない」という緊張感も演出できる。

### 未決

- スキル使用による成長に、単純な使用回数カウンター以上の仕掛け（判定の成否・隠しパラメータとの絡み）を持たせるかどうか
- 休息の質（宿屋のグレード・野宿・馬車内での休息）がレベル反映の効率やボーナスに影響するかどうか
- キャラメイクの質問診断制を採用するか、手動クラス選択のみにするか

# 3. 「書類読解」スキルと世界の識字率

契約書のプロ値を正しく読めるかどうかは、「書類読解」という新しいスキル軸として提案された。

- 「普通」ではノーコストでデフォルト取得済み。

- 「難しい」ではスキルポイントを割り振らねば取得できない選択科目になる。

- 未取得の場合、契約書を見せられても数値の意味が分からない、あるいは誤読するペナルティ。

これにより、隠しパラメータの数だけ対応スキル（魔術の知識＝影響度、目星＝馬車の劣化、書類読解＝プロ値）が並び、「情報収集そのものがキャラビルドの一部になる」という構造が生まれる。限られたスキルポイントの中でどれに投資するかが、プレイスタイルの分化を生む。

# 4. 難易度＝世界の個性という発想への転換

識字率のノーコスト取得可否をきっかけに、「ゲーム難易度」を無機質な数値調整ではなく、「どんな世界に生まれ落ちたか」という世界観設定そのものとして扱う方向に議論が発展した。

## 4-1. 転換のポイント

- 「易しい＝弱者への配慮」ではなく「統治が行き届いた、情報インフラの整った地方を選んだ」という体裁になり、心理的抵抗（イージーモードへの後ろめたさ）を緩和できる。

- 「識字率」「治安」「インフラの整備度（耐久度の減りやすさ）」「情報開示レベル」「苦難の乙女発生率」など、個別の軸としてカスタム可能にする。

- 既存メモの「V1.04幼馴染誘拐祭りバージョン」や「仲間運Very Hard」も、単なるバグ・難易度ではなく「そういう土地柄・星の下に生まれた世界」として物語的に一貫して説明できる。

## 4-2. 二層構造の設定画面

| **層** | **内容** |
| --- | --- |
| プリセット選択（簡単／普通／難しい） | ワンクリックで各項目が一括決定。初見・気軽に遊びたい層向け |
| 詳細設定 | 個別項目だけカスタム可能。「難しいベースだが識字率だけ上げる」等のこだわりに対応 |

プリセット名は「簡単・普通・難しい」という無機質なラベルではなく、世界観を含めた名前（例：「豊かな中央領」「辺境の無法地帯」）にすることで、選択そのものが最初からロールプレイの一部になる。難易度間の暗黙の序列（易しい＝退屈、難しい＝偉い）も解消しやすくなる。

# 5. 世界設定の保存・共有

プレイヤーが作成した世界設定を、名前・サマリ・タグ付きで保存・共有できる仕組み。V1.04のようなミームが偶発的に生まれるのを待つのではなく、最初から共有前提で設計する。

## 5-1. 共有時に持たせたい情報

- 名前・サマリ・タグ（基本の3点セット）

- プレイ時間の目安

- 代表的なエピソード・スクリーンショット（世界の“空気”を一発で伝える）

- 由来・派生関係（「〇〇さんの世界をベースに一部変更」のような系譜の可視化）

- プレイ後の評価・感想の集積（自己申告ではなく実プレイヤーの声による補強）

- あえて入れないもの：無機質な「難易度スコア」の自動算出。数値ランキングは「難易度ではなく世界の個性」という思想と矛盾するため、あくまで人間の言葉（サマリ・タグ・感想）で語られる世界であり続ける方針。

## 5-2. データ形式

- フォーマットはJSON。設定項目は基本的にキーと値のフラットな組み合わせが中心で、XMLの入れ子構造の強みは必須ではない。共有プラットフォームとの親和性、編集のしやすさからもJSONが妥当。

- JSON5（コメント記述可）も検討したが、コメントはゲーム側の読み込みには影響せず人間同士のメタ情報に留まるため、同じ目的は既存の「サマリ」フィールドで代替可能。標準JSONのままで問題ないと判断。

- 前方互換性：知らないキーは無視する。新項目が増えても古いデータがそのまま読み込め、逆に新しいデータを古いバージョンで読んでもクラッシュしない。知らないキーはデフォルト値にフォールバック。formatVersion フィールドを必須にしておくと、仕様のバージョン判定がしやすい。

- 保存形式は差分方式を採る。既定値テーブルをゲーム側が保持し、世界設定ファイルには既定値からの上書き分だけを書き込む。詳細は世界生成仕様（セクション6参照）を参照。

**サンプルJSON（旧版・低レベルsettings直書き）**

{
  "formatVersion": 1,
  "worldName": "辺境無法地帯",
  "summary": "識字率が低く、道は荒れ、仲間もすぐには心を開かない世界",
  "tags": ["ハードコア", "低識字率", "苦難の乙女多発"],
  "settings": {
    "literacyRate": "low",
    "security": "low",
    "infrastructureDurability": "fragile",
    "damselEventFrequency": "high"
  },
  "seed": "a3f9c2",
  "derivedFrom": null
}

# 6. 時代・様式プリセットと世界設定の階層化（詳細は世界生成仕様を参照）

セクション4の「難易度＝世界の個性」を発展させ、「時代プリセット（`eraPreset`）」「様式プリセット（`stylePreset`）」という2軸で世界の性格を決める仕組みを検討した。あわせて、ギルド構成・隠しパラメータの可視化（`hiddenParameters`）・亜人種族の有無（`demihumans`）も、同じ階層構造（プリセット既定値＋個別上書き、国→地域→町で継承・上書き）に乗せる形で整理した。

決定事項の要点：

- `eraPreset`：史実のヨーロッパ史準拠の4段階（`early_medieval` / `high_medieval` / `late_medieval` / `renaissance`）。時代が進むほど制度・インフラが整う。モンスターの存在は全時代共通の前提とし、「移動宮廷＝巡回討伐を兼ねた武装集団」「街道の安全＝王権の正統性の指標」という読み替えで史実とモンスター脅威度を両立させる
- `stylePreset`：時代を選ばない様式軸。`eraPreset` とは独立し、任意に組み合わせ可能。公式プリセットは `narrowpa`（なろう＋ヨーロッパ。ゲーム的利便性が常識の世界）と `historical_fantasy`（イバラギーッパ、仮称。史実の重みを残した折衷様式）の2種。ユーザー定義の様式も同じ構造で保存・共有可能（「サイタマーッパ」等の地方名ミームを想定）
- ギルド構成：宿屋・酒場・冒険者（協会）の統合／分離パターンを5類型に整理し、国→地域→町の階層で継承・上書き
- `hiddenParameters`：耐久度・影響度・プロ値などの見え方を `hidden` / `appraisable` / `visible` の3段階で世界設定から一括制御
- `damselEventFrequency` 等の「味付け」項目は、プリセットに連動しない独立項目として `settings` 内に残す
- `demihumans`：亜人の有無（`presence`）・関係性（`relation`）・種族リスト（`races`、将来の `traits` 拡張を見据えオブジェクト配列で保持）

具体的な既定値テーブル、データ構造、JSONサンプルは `daggerfall_dq_world_generation_spec.md` に独立ドキュメントとして切り出した。今後、世界生成まわりのルール・データを更新する際はそちらを更新する。

# 7. 今後の検討課題（オープンイシュー）

- 御者・馬丁のプロ値と、影響度・目星判定との間で情報の食い違いが起きた場合の扱い（どちらを信じるかのジレンマ設計）

- 契約書の偽造・誇張申告をどこまでゲームシステムに組み込むか（「難しい」世界でのみ有効にするなど）

- 共有プラットフォームにおける「効率重視の最適解」への画一化リスクと、ロールプレイ的な魅力を評価軸にするための仕組みづくり

- 世界生成まわりの詳細な未決事項（既定値テーブルのバージョニング、亜人 `traits` 設計、`stylePreset` の共有フォーマット、設定画面のUI設計等）は `daggerfall_dq_world_generation_spec.md` のセクション8にまとめた

# 8. 史実イベント群と古代文明の裏設定（自由連想セッション）

セクション6の `eraPreset` を肉付けする形で、史実のヨーロッパ史から個別のトピック（新大陸作物、疫病、宗教・十字軍、古代文明）を自由に連想し、既存の階層構造にどう落とし込めるかを検討した。今回は方向性の洗い出しに留め、仕様への確定的な反映は行っていない。

## 8-1. 新大陸作物（じゃがいも・トマト等）

- じゃがいも・トマトは史実では新大陸原産で、ルネッサンス期以前のヨーロッパには存在しない。`early_medieval`〜`late_medieval` では「無し」が史実に忠実
- 他の新大陸作物：トウモロコシ、カカオ、唐辛子、タバコ、ひまわり。唐辛子が無い世界では「辛味」は胡椒・生姜・辛子（マスタード）頼りになり、香辛料貿易の重みが増す
- 史実では両作物とも「毒がある」「悪魔の植物」と長らく警戒され、じゃがいもは聖職者や王による普及キャンペーンでようやく広まった。この「新奇な作物への不信」は、異端・魔術との結びつきを疑われる、あるいは王や教会が布教役に回るという物語装置に転用できる
- ファンタジー的な代替案：新大陸の代わりに「古代文明の遺跡から回収された作物」「妖精郷からの贈り物」「亜人種族が古くから栽培していた作物」に置き換えても、受容の摩擦という構造は保てる
- 「大陸間の接触」を一回性の世界史イベント（`eraPreset` とは別軸）として、「接触前」「接触直後の混乱期」「交換が定着した後」の段階を持たせる案
- 既存の `potato-church-sim`（ポテト教会司祭が飢饉を救う村おこしシム構想）は、じゃがいも伝来後の世界を扱っており、この世界設定と地続きにできる

## 8-2. 疫病（黒死病相当）

- `late_medieval` の既定値（都市の成熟・疫病後、傭兵の台頭）に直結。史実では人口の3〜5割減、農奴制の崩壊、賃金上昇、ギルドの閉鎖性強化（既得権益防衛）といった影響があった
- ファンタジー化のパターン：（1）通常の疫病（原因不明・神罰と解釈）、（2）モンスター由来（呪詛・瘴気・特定モンスターの生息域から広がる「穢れ」）、（3）魔術的な疫病（禁呪の失敗、古代文明の遺物が原因）
- 検疫・隔離制度（ヴェネツィアの40日検疫、quarantineの語源）：疫病発生地から来たパーティが町に入れない、という関所イベントに転用できる
- 当時の医学（四体液説）と魔術医療の境界が曖昧な世界なら、「まともな医者」と「怪しい治療師」の対立軸ができる
- 疫病時の集団心理（鞭打ち苦行者、特定集団への迫害等の史実の負の側面）は、ファンタジーの「魔女狩り」「異端審問」の燃料に転用可能だが、扱いには慎重さが要る
- 世界設定パラメータ案：`plagueHistory`（発生済み／進行中／未発生、原因の型：自然／呪詛／古代文明）。原因を隠しパラメータ的に扱うと謎解き要素になる

## 8-3. 一神教・十字軍

- 既存メモの「教会と異端」「魔力の正体をめぐる教義対立」と接続
- 叙任権闘争（教皇権と世俗権力の対立）：魔術師ギルドの任命権を教会と王権のどちらが持つか、という対立に転用できる
- 異端審問と禁書目録：古代文明の魔導書がそのまま禁書リストに入る構造と直結
- 騎士修道会（テンプル騎士団等）：冒険者ギルドとは別に、信仰に基づく戦闘集団を置く案
- 巡礼路：危険な道中の末に聖地へ辿り着く、というクエスト構造。宿・土産物・案内人からなる巡礼経済圏
- 十字軍の遠征先を「魔物の巣窟」「異教の古代文明」に置き換えると、正当化のレトリック（聖戦の名目での略奪）がそのまま使える
- 十字軍相手側（史実ではイスラム世界等）の文明水準が当時のヨーロッパより高かった史実を踏まえ、「征服する側が文化的に遅れている」逆転構造も使える

## 8-4. 古代文明の裏設定（DLC構想）

古代ローマ帝国をモデルにした「古代文明＝現代文明＋魔法」水準の技術・社会を持つ失われた文明という裏設定を検討した。本編の軽めのトーン（「めんどくさいけど自由度が高いドラクエ」）を守るため、**この裏設定はDLCとして本編から切り離す方針**とした。

### 8-4-1. 技術水準とオーパーツ

- 古代文明は現代文明＋魔法相当の技術力を持ち、遺跡から「オーパーツ」が発掘されうる
- 無制限に流通すると中世社会の設定と矛盾するため、歯止めとして以下を検討：
  - 希少性で縛る（大半の遺跡は空か瓦礫）
  - 使用条件で縛る（起動に膨大な魔力・特殊な血統・失われた言語の知識が必要）
  - 崩壊の原因そのものにする（古代文明はその技術力ゆえに自滅した。オーパーツの多くは危険物）
  - 文明の断絶を徹底する（古代の科学体系と現在の魔術体系は接続しておらず、オーパーツは動くが原理不明のブラックボックスのまま）
  - 上記のうち「崩壊の原因」＋「文明の断絶」の組み合わせが、史実（ローマのコンクリート製法喪失等）とのアナロジーも効いて有力
- 遺跡荒らし（トレジャーハンター）という専門職案：既存の御者・馬丁・鑑定士の系譜に連なる。「プロ値」に相当する「危険物識別能力」、無所属の盗掘者と公認の探索者組合（発掘物届出義務と引き換えにアクセス権・解呪師同行支援を得る）の対比
- `hiddenParameters` に `artifactDanger`（hidden / appraisable / visible）を追加する案

### 8-4-2. 死霊術帝国という裏設定

- 古代ローマの奴隷労働経済（戦争捕虜・征服地からの供給に依存、鉱山・農園・建設・家事労働を支えた）を、死霊術による死体使役に置き換えるアイデア
- 史実のローマ衰退説（新規征服地＝奴隷供給源の枯渇が経済を圧迫）と同じ構造を、「供給源＝戦死者・処刑者・疫病による死者」として継承できる
- セクション8-2の疫病と接続：疫病の犠牲者を死霊術で労働力に転換する帝国、という設定にすると、疫病が古代文明の経済サイクルの一部になり、「なぜ古代文明は疫病を放置・助長したのか」という不穏な問いが生まれる
- 古代文明滅亡の筋書き案：死者労働力の供給が追いつかなくなった、あるいは使役された死者が反乱・暴走した
- 現在の世界への影：
  - 一神教が死霊術と死者冒涜を最大の禁忌とする教義的根拠になりうる（「古代文明＝死者を冒涜した異教」への反面教師としての正統性）
  - 死霊術の理論書は禁書の筆頭
  - 遺跡内の「いまだ機能している死体労働者」は、モンスターと犠牲者の中間的な存在として重い扱いになりうる
  - 死霊術の労働力供給に亜人種族が使われていた歴史があれば、現在の人間・亜人関係の緊張の起源として使える
- トーンの選択肢（未決）：（1）告発・悲劇として明確に「悪」と位置づける、（2）両義的に描く（独自の合理性があった、断罪自体が単純化されている）、（3）背景の説明装置に留め、直接の掘り下げ対象にしない
- **DLC切り分けの設計指針**：本編内の古代文明への言及は伝聞・噂・断片的な考古学的発見に留める（話題ウィンドウで開示されても「よく分かっていない」で止める）。死霊術・死体使役に関わる要素は本編の魔術体系とは別の「禁忌の技術体系」として最初から切り分けておく。DLC関連の世界設定項目は「知らないキーは無視」の前方互換性ルールに乗せ、DLC無し環境では単に情報が出てこないだけで本編データ構造が壊れないようにする

## 8-5. 大気中のマナ濃度

- 魔術の使いやすさ（詠唱成功率・威力、低魔力でも発動できるか）を左右する環境変数として導入を検討
- 地理的な濃淡：史実の気候・地形差のように地域ごとにムラがある（「霊脈」的な発想、または「聖地」「呪われた地」）
- 古代文明との接続：古代文明期はマナ濃度が今よりずっと高かった、という設定にすると、現在は同規模の魔術文明が再現不可能という「技術の断絶」の理由付けになる。史実のローマ温暖期終焉と3世紀の危機の重なりともアナロジーが効く
- 産業への影響：マナが薄い土地の都市は、魔術に頼らず職人技・水車・馬力などの非魔術的インフラで発展する
- 時間変動軸：`eraPreset` の既定値テーブルに組み込み、「古代文明期＝超高濃度」「中世前期＝激減直後で魔術の担い手が激減」「ルネッサンス期＝緩やかに回復」というカーブを引ける案。中世の魔術衰退・錬金術への変質を、教会の弾圧だけでなく物理的理由でも二重に補強できる
- データ構造案：
```
"manaDensity": {
  "global": "low",
  "regionalVariance": "high"
}
```
  - `global`：世界全体の基調濃度
  - `regionalVariance`：地域差の大きさ自体も可変（低いと均質、高いと聖地・不毛の地の落差が激しい）
- 国→地域→町の階層継承にそのまま乗り、「国全体は薄いが古代遺跡の近くだけ異様に濃い」等の局所例外を表現できる
- 本編には「濃度が薄い」という結果のみ残し、「なぜ薄いのか」の答え（古代文明・死霊術帝国の顛末）はDLC側に隠す、という8-4と同じ切り分け方を想定

## 8-6. 妖精

- 史実・伝承の妖精像は多様：ケルト・アイルランド系（気まぐれで危険、人攫い、時間の歪み、鉄を嫌う）、ゲルマン・北欧系（エルフ・ドワーフ。現代のハイエルフ像はトールキン以降の再解釈）、取り替え子（チェンジリング）伝承、家の精霊（ブラウニー的存在。家事を手伝うが供物を要求し、粗末に扱うと祟る）
- 現代ラノベ的な「お助けキャラ」像は、伝承のうち家の精霊・使い魔的側面を抽出して優しく再解釈したもの
- 方向性を「史実寄り（気まぐれで危険、作法を知らないと痛い目）」「narrowpa寄り（素直な契約パートナー）」の一方に決めず、**両方を個体差として混在させる**方針とした。見た目は可愛いお助けキャラだが、名前の扱いや約束事を誤ると伝承通りの気まぐれさ・危険さが顔を出す、という二段構えが有力
- マナ濃度との接続：マナが濃い土地（古代文明の遺跡跡、聖地）ほど妖精が多い・強い。中世プリセット（マナが薄い）では希少・弱体化しており、「昔はもっと妖精がいた」という語りが古代文明期の高マナ濃度設定と一貫する。人間文明の拡大＝マナの希薄化は妖精にとって生存圏の縮小であり、人間への敵意・警戒の理由になりうる
- 亜人種族（`demihumans`）との住み分け：`demihumans` は人間と同じ社会構造で暮らす種族（エルフ・ドワーフ・獣人等）、妖精は自然そのものに近く契約・供物でしかやり取りできない存在として区別する案。トールキン的ハイエルフは亜人寄り、ケルト的エルフは妖精寄り、という整理も可能
- ゲームシステムとの接続：妖精との関係を `influence`（人間キャラへの忠誠・好感）とは別の「取引・契約の遵守度」の軸として持たせる案。「妖精作法」のような専門知識スキルを、書類読解スキルと並ぶ位置づけで検討
- データ構造案：
```
"fae": {
  "presence": "rare",
  "dispositionDefault": "capricious",
  "bargainRequired": true
}
```
  - `dispositionDefault` はあくまで世界全体の平均的傾向で、個々の妖精キャラ（お助け役の相棒等）はそこから外れた個性として物語側で自由に設計できる、という二層構造

## 10-1. 史実トピックの追加候補

- **婚姻・血統・相続**：政略結婚、持参金、相続争い。貴族の血統に魔力適性が遺伝する設定にすると、政略結婚が「魔力の血を薄める/濃くする」道具になり身分制と魔術体系が結びつく。長子相続と非長子（次男・三男）の処遇が、騎士団・聖職者・傭兵・冒険者になる動機づけとして使える
- **都市 vs 農村の非対称**：史実の人口の大半は農村。農奴制、賦役、領主裁判権。冒険者の出自（都市民／農村出身）で識字率・書類読解の初期値を分けるとキャラメイクに説得力が出る。農村はモンスター被害を最も直撃で受ける層で、都市の安全は農村の犠牲の上に成り立つという構図が作れる
- **言語の断絶**：共通の書き言葉（ラテン語相当）と多様な口語（俗語）の分離。「書類読解」とは別に「他言語理解」スキルを分ける、あるいは書類は共通文語で書かれているため識字率が低くても書類読解さえあれば読める、という設計案。旅の摩擦（通貨・度量衡）に言語も加えられる
- **傭兵と戦争経済**：`late_medieval` の既定値「傭兵の台頭」の掘り下げ。コンドッティエーレ（イタリア傭兵隊長）のように、雇い主を裏切ったり戦争を長引かせて稼ぐインセンティブがあった史実。冒険者ギルドと傭兵団の違いを明確にすると、パーティがどちらに見られるかで町の対応が変わる設計ができる
- **異端そのものの中身**：カタリ派・ヴァルド派等の史実異端運動は教義対立というより教会の富と権力への批判という社会運動的側面が強かった。「異端＝魔力の私的独占を否定する平等主義」のような政治的異端像にすると、単なる悪役にならず既存の「難易度＝世界の個性」の設計思想とも響き合う
- **旅芸人・吟遊詩人という情報伝達層**：識字率が低い世界での口承文化（歌・物語）は実質的なニュースメディアだった。話題ウィンドウの「覚える」情報が書類だけでなく吟遊詩人の歌経由でも開示される、という第三の情報経路の案。書類読解が不要な代わりに、内容が誇張・改変されている可能性（信頼性の低下）を持たせられる
- **気候そのもの**：史実の中世温暖期→小氷期のような気候変動は、農業生産・飢饉・疫病の引き金として一体だった。マナ濃度と同様に `eraPreset` へ「気候トレンド」を持たせると、飢饉頻度や街道の通行可能期間（冬季閉鎖）に説得力を足せる

## 10-2. 殺人教団

## 10-3. サプリメント／DLC構想 18本立て

裏設定・拡張要素を本編から切り離すDLC・サプリメントとして、以下の18本のタイトル案が出た。

- **「本当はヤバい古代文明」**：セクション8-4の古代文明・死霊術帝国・オーパーツ・高マナ濃度期を扱う。「縦の軸（歴史・起源）」。遺跡荒らし、禁忌の技術、古代文明がなぜ滅びたか、が主軸
- **「突撃！隣のダークファンタジー」**：殺人教団（10-2）、異端審問の裏側、十字軍の欺瞞、疫病下の集団心理など「今の世界の日常に潜む闇」を扱う。「横の軸（同時代・日常への浸透）」。古代文明という過去の話ではなく、現在進行形で隣町・隣人が実は、という切り口。**時代・世界の状態を選ばない「日常の闇の常設資料」として定義する**（アポカリプス前・途中・後のどの世界でも、含む場合も含まない場合も使える汎用の闇）。詰め込みすぎを避けるため、アポカリプスの時間軸（前・途中・後）は本タイトルの範囲から外し、別シリーズとして切り出す（後述）。疫病については、集団心理（人間の闇）の部分のみ本タイトルに残し、世界史イベントとしての疫病はアポカリプス側に寄せる
- **アポカリプス系（前・途中・後）**（タイトル未定、別シリーズ）：世界の状態そのものを扱う時間軸のサプリメント群。「突撃！隣のダークファンタジー」（日常の闇・時代不問）とは軸が異なるため、独立シリーズとして切り出した。`eraPreset` とは独立した一回性の世界史イベント軸（キー案：`apocalypseStage`。「前／途中／後」の3段階。セクション8-1の「接触前・混乱期・定着後」の段階案と同型）として、世界設定に乗せる想定。含む世界と含まない世界を最初から選べる設計にする。トーン案は、前＝サスペンス・陰謀、途中＝パニック・生存（検疫・関所イベント、8-2）、後＝荒廃・再建
  - **未決**：アポカリプスの型（疫病型／古代文明の再来型／魔界（亜次元）の侵入型）。型によって3冊の題材が変わる。魔界侵入型なら「君たちは狙われている！魔界ヒッチハイクガイド」との役割分担、古代文明型なら「本当はヤバい古代文明」との接続を要整理
  - **留意**：途中・後は個人〜パーティ単位の冒険という本編スコープを大きく変えうる（「辺境伯RTA簡単ガイド」と同様の留保）
- **「亜人がいっぱい」**：`demihumans` の拡張パック。本編の既定値（少数・最小限の種族リスト）を大幅に増量する。種族追加（獣人、竜人、小人種、巨人種等）に加え、セクション6-6で保留していた `traits`（寿命・得意分野・種族間関係・社会構造への補正）の本格実装、種族ペアごとの `relations` マップ、種族別ギルド（ドワーフ職人組合等）を扱う範囲。「本当はヤバい古代文明」で死霊術帝国が亜人を労働力に使っていた歴史がある場合、特定種族の起源や人間・亜人関係の緊張の回収先にもなる
- **「神格大全」**：一神教の唯一神の教義・奇跡の詳細化に加え、地方神・異教・精霊信仰まで含めた世界の信仰の全体像を扱う。既存メモに散在する各世界観の神格・信仰要素（`santanyaan` の商業都市の守護神、`potato-church-sim` のポテト教会・トマト教会のような対立宗教構造）を横断的にまとめる役割も持てる。マナ濃度（8-5）と接続すれば「神々もマナの希薄化で弱体化している」という古代文明期からの力の衰退ストーリーを描ける。神・精霊（妖精）・亜人という超自然的存在の階層整理の起点にもなる

- **「君たちは狙われている！魔界ヒッチハイクガイド」**：亜次元・魔界側の存在が地上に干渉してくるサスペンス／コメディ寄りの切り口。タイトルの「狙われている」がプレイヤー（読者）に直接語りかける構造で、「突撃！隣のダークファンタジー」とトーンが近い

  - **収録職業（案）**：聖＝祓魔師（教会公認、教区司教の許可が必要）、異端審問官（妖魔と異端の線引きが仕事）、騎士修道会士（8-3）、巡礼路の守り手。俗＝冒険者・討伐請負人（ギルド／協会所属）、傭兵団の対魔部隊（「易しい傭兵」と接続）、領主付き狩猟官／街道守（街道の安全＝王権の正統性）、検疫官（8-2）、解呪師・鑑定士（8-4-1）

  - **既存タイトルとの関係**：「突撃！隣のダークファンタジー」の異端審問の裏側（暗部）に対する、表の真面目な専門書という対比。10-3-2の栄達ルートのうち司教ルート・辺境伯ルートの現場職版。栄達ルート実装のPDF特典に同梱する案も自然
  - **未決**：（1）序文の宣言だけで魔女狩りとの対比を済ませるか、本文中で誤認例を反面教師として扱うか（後者は「突撃！隣」と役割が重なる）。（2）妖魔と亜人・妖精（8-6）の境界をどこまで整理するか。（3）タイトルの型を「教科書・入門書系」に入れるか、「権威ある専門書パロディ」の新系統を立てるか
- **「易しい傭兵」**：『やさしいC』などのプログラミング入門書シリーズのタイトルパロディ。傭兵という職業・システムを初心者向けに噛み砕いて解説する入門書・マニュアル本の体裁。想定コンテンツ例：傭兵団の格付け・階級制度、契約書の読み方（既存の「書類読解」スキルと直結）、傭兵と冒険者ギルドの違い（10-1で既出の論点）、裏切り・戦争長期化のインセンティブという「業界の裏事情」をあえて教科書的に淡々と解説する構成。章立ても「第1章 傭兵とは何か」「第2章 雇用契約の基礎」のような実際の入門書の目次構成を模す案。他のタイトルとも異なる**教科書・実用書パロディ**という系統

  **栄達の起点**：旧D&D（OD&D〜AD&D 1st）には「Name Level」という慣習があり、戦士9レベルで砦持ちの領主、魔術師11レベルで塔持ちのアークメイジになる等、戦闘能力の閾値到達に応じて自動的に統治者資格を得るルールが存在した。りひにーのイメージはこれとは異なり、**「100人隊長からの栄達」**——実務・軍功を部隊単位で積み重ね、統率者としての実績を評価された結果として爵位を得る、という因果連鎖。史実のコンドッティエーレ（イタリア傭兵隊長）が実際に都市国家の支配者に成り上がった例（フランチェスコ・スフォルツァのミラノ公就任等）がモデルに近い。D&D的な「強さの飛躍」ではなく、**現代的に納得しやすい実務・功績主義の因果**を選んだことで、既存メモが一貫して採ってきた設計方針（プロ値・書類読解・ギルドの査定など、隠しパラメータを第三者が評価・記録する仕組み）ともそのまま接続する

  既存要素との接続：辺境伯という爵位自体が史実でも「辺境（マルク）を守る軍事的責任者」の成り立ちで、最初の会話にあった「移動宮廷＝巡回討伐を兼ねた武装集団」「街道の安全＝王権の正統性の指標」がそのまま領地経営のテーマになる。個人単位で雇っていた専門家（御者・馬丁・プロ値システム）が領地スケールで代官・徴税官・衛兵隊長の雇用・信頼度管理に拡大する。「易しい傭兵」で解説される傭兵稼業の基礎知識が、この栄達ルートの前提知識として機能し、両サプリメントが入門編・発展編の関係になる。「農奴サバイバルガイド」とは支配する側／される側で対になる関係。プレイヤー自身がギルド構成（セクション6-3）の「国→地域→町」の階層における設定者側に回る、という新しいゲームプレイの軸。識字率・書類読解についても、読み解く側から書類を発行する側への逆転が起きる。**本編のシステム規模（個人〜パーティ単位の冒険）を大きく超える可能性があり、スコープ外になりうる**という留保付きで記録
- **「象牙の塔では教えてくれない魔術」**：セクション10-3-2の大学（塔）ルートが扱う公認の学問体系に対し、そこでは教えられない非公認・実用の民間魔術を扱う。死霊術・古代文明の禁書（8-4）とは別軸の、市井の生活魔術・まじない・呪い返しといった「大学が黙殺する、けれど確かに効く」技術体系。大学ルートの裏面として機能し、正規の学問とは別に生き延びてきた口伝の魔術という位置づけになる
- **「天文学または占星術のススメ」**：史実では表裏一体だった天文学と占星術をあえて並記したタイトルで、「どちらを信じるか」自体をプレイヤーのロールプレイに委ねる。マナ濃度（8-5）の時間変動、吉凶日・遠征の出発日選びといった環境変数を、教科書的な語り口で読み物化する。「易しい傭兵」と同じ**教科書・実用書パロディ**の系統に連なる
- **「◯◯商店エーテル通信カタログ」**：通販カタログという体裁の新しい型。`stylePreset` の地方名ミーム（サイタマーッパ等）と同様に、店名（「◯◯商店」部分）をユーザー・MODで差し替え可能なテンプレートとして設計できる。エーテル通信という魔術的な通信販売の建て付けが、マナ濃度設定の物語的な使い道を増やす。書類読解（誇張・偽造表示を見抜く）、`artifactDanger`（危険な商品の識別）、旅・輸送システム（遠隔地配送＝キャラバン便乗の延長）と接続する
- **「じゃがいも・トマトの受容史」**：セクション8-1の新大陸作物の受容摩擦を独立タイトル化したもの。じゃがいも・トマトが「毒がある」「悪魔の植物」と警戒された史実、王や教会による普及キャンペーン、ファンタジー的な代替案（古代文明の遺跡作物、妖精郷からの贈り物）を、一つの読み物として掘り下げる。「本編は軽め、重い設定はDLC・特典PDFへ」という方針のもと、`potato-church-sim` との地続き感を補強する資料としても機能する
- **「明日話せるマナ濃度の時代変遷」**：セクション8-5のマナ濃度を独立タイトル化したもの。雑学系新書のパロディタイトル（「明日話せる」）で、`manaDensity` の時代カーブ（古代文明期＝超高濃度、中世前期＝激減直後、ルネッサンス期＝緩やかな回復）を、史実のローマ温暖期終焉・3世紀の危機とのアナロジーを添えて語る。「精霊の秘密」「本当はヤバい古代文明」と同じマナ濃度設定を、より軽い雑学書のトーンで扱う棲み分け
- **「聖職者出世双六」**：栄達ルート3類型（10-3-2）のうち司教ルートに対応する読み物。「双六」という形式が、叙任権闘争・教区運営・異端審問との向き合いといった不確実性の強い出世コースを、ゲーム的な語り口で見せる。10-3-2のPDF特典構想で言及されていたタイトルを、サプリメント本体一覧にも正式に載せ、栄達ルート実装（辺境伯・司教・大学）購入特典としての役割を引き続き兼ねる

「亜次元の歩き方」に関連して、魔界が「亜次元」（物理的に繋がっていない別空間、門・儀式・裂け目でしか行き来できない）なのか「地下世界」（地続き、ダンジョンを掘り進めば繋がる）なのかという設定分岐も検討した。両方を採用し、地下世界を掘り進めた先が実は亜次元への「薄い場所」だった、という二段構えの案が有力：「本当はヤバい古代文明」の遺跡探索の最深部が、地下世界ではなく異次元との境界だった、という繋がり方ができる。

| 隣接システム | プロ値、御者・馬丁の雇用管理 | 異端審問、禁書目録（セクション8-3） | 魔術の知識（影響度）、書類読解、禁書（セクション8-4） |
| 対になるサプリ | 農奴サバイバルガイド | 突撃！隣のダークファンタジー | 本当はヤバい古代文明 |

- **司教ルート**：セクション8-3の叙任権闘争（教皇権vs世俗権力）がそのまま任命プロセスの政治性として機能する。司教は異端審問の実務を担う立場にもなりうるため、殺人教団（10-2）や異端狩りへの向き合い方という重い選択が生まれる。識字率・書類読解の観点では、教会法・破門状・贖宥状を発行する側に回る
- **大学（塔）ルート**：史実のヨーロッパ最古の大学（ボローニャ、パリ、オックスフォード）が学者・学生のギルド（ウニウェルシタス）として自然発生した経緯を踏まえ、大学を「学問のギルド」としてセクション6-3のギルド構成の議論に接続する。ルネッサンス期の「知の再発見」（最初の会話に出た、古代の魔導書の再発見という流れ）の実務拠点として機能させられる。既存メモの「メディチ的パトロン制：魔術師も画家も、有力家門に抱えられて競う」というアイデアが、塔を持つ魔術師＝有力パトロンを獲得した学者、という形で実装レベルに接続する。大学の自由な研究（特に古代文明の魔術研究）と教会の統制（禁書目録・異端審問）の緊張関係も史実に忠実な形で持たせられる

3ルートはいずれも「実力そのもの」ではなく「実務・実績を第三者（軍功なら上長、信仰なら教会、学問なら学者仲間・パトロン）が評価する」という共通の因果構造を持ち、既存メモの一貫した設計思想（プロ値・書類読解・ギルドの査定）からブレていない。

### PDF特典構想

DLC購入特典として、ゲーム内システム（栄達ルートの実装）と対応する「攻略本・設定資料PDF」を同梱する案。

- ゲームの中身（栄達ルートの実装）と、外側の資料（「易しい傭兵」「辺境伯RTA簡単ガイド」等のパロディ書籍）が同じ悪ノリで一貫している、という構造そのものを狙う
- 実在のPCゲーム文化にある「デジタルデラックス版特典アートブック・PDF設定資料集」の伝統を踏襲する形で、違和感なく実装できる
- ゲーム内実装だけでは説明しきれない背景（史実ネタ、パロディの元ネタ、「無駄に精緻」な設定の詳細）を、PDFという体裁でこっそり明かす場として機能させられる
- 想定される対応関係：DLC「本当はヤバい古代文明」購入特典 → PDF「亜次元の歩き方」抜粋、または大学（塔）ルートの設定資料。栄達ルート実装（辺境伯・司教・大学）購入特典 → PDF「易しい傭兵」「聖職者出世双六」「大学ルートの入門書」（この2本はセクション10-3のサプリメント本体一覧にも正式追加済み。本体一覧に載る独立タイトルであると同時に、栄達ルート実装のPDF特典としての役割も兼ねる、という二重の位置づけ）
- 設計上の実利：本編のテンポを崩さずに「無駄に精緻」な設定（じゃがいもの受容史、マナ濃度の時代変遷等）をPDFに逃がせる。「本編は軽め、重い設定はDLC」の方針を、DLC内部でさらに一段細分化する形で適用できる。セクション5-1の「サマリ・タグで語られる世界」（無機質な数値化を避ける方針）とも、人間の言葉で書かれた読み物という形式面で一貫する

## 10-4. Glyphfall TRPG化の思いつき

- 一瞬の思いつきとして、Glyphfallの設計をTRPG（テーブルトークRPG）として作る案が浮かんだ
- 現在の設計思想がすでにTRPG的な要素を多く含んでいるという指摘：
  - `eraPreset`/`stylePreset` の階層プリセット構造は、GURPSやSavage Worldsのセッティング本の作法そのもの
  - 話題ウィンドウ／「覚える」は、PbtA系やGUMSHOEのような「情報を得る＝物語が進む」ナラティブ系TRPGの技法、あるいはCoC（クトゥルフ神話TRPG）の「アイデア・目星ロール」に近い
  - 隠しパラメータ＋対応スキル（目星・魔術の知識・書類読解）は、TRPGの技能表の発想そのもの
  - サプリメント構想（10-3）は、そのままTRPGのキャンペーンセッティング本のタイトルとして通用する
  - 旧D&D（OD&D〜AD&D 1st）の「Name Level」（戦士9レベルで砦持ちの領主になる等、戦闘能力の閾値到達で自動的に統治者資格を得るルール）も、TRPG由来の慣習として「辺境伯RTA簡単ガイド」（10-3）・栄達ルート3類型（10-3-2）の検討時に参照した
- CRPGとTRPGの違い：TRPGはGM（人間）が即興で判断するため、「番人が新人か判定する」ような曖昧な会話フローが、実装せずそのまま成立する。今addendumで検討している複雑な分岐（語順で意味が変わる等）は、CRPGでは実装コストが跳ね上がるが、TRPGならGMの裁量一つで済む
- 実用的な利点の指摘：世界設定・ルール検討の副産物としてTRPG的にまとめ直すことで、CRPG実装前に「TRPGのセッションとして一度動かしてみる」形の、実装前のバグ出し・面白さの検証ができる可能性

### Glyphfall TRPG基本ルールブックの本体同梱構想

- 「本体にGlyphfall TRPG基本ルールブックが入ってもいい」という着想が出た。DLC特典PDF（10-3-2）よりさらに一歩進み、CRPG本編そのものに基本ルールブックを同梱する案
- 構造的な妥当性：`eraPreset`/`stylePreset`の階層プリセット、話題ウィンドウ、隠しパラメータ＋対応スキルといった既存の設計が既にTRPGのルールブックとほぼ同じ形をしているため、TRPG化は新規制作というより既存の設計文書の清書に近い。`daggerfall_dq_world_generation_spec.md`のような仕様書は、CRPG向け技術仕様であると同時にほぼそのままTRPGのGMガイドとして機能しうる。CRPG本編＋DLC群（10-3の18本＋10-3-2の3ルート）が、TRPGの基本ルールブック＋キャンペーンセッティング本群にまるごと対応する二重構造が既に出来上がっている

**Geminiちゃんからの提案（他AIとの並走検討）**：この構想について、Geminiちゃんから以下の具体案が出た。

- 「ゲーム内の仕様」がそのまま「TRPGの判定ルール」になる：ロード画面等で「より詳しいダメージ計算式や迷宮遭難の判定基準は、同梱の基本ルールブック第4章をご参照ください」と案内が出る仕様。CRPGの内部計算ロジックを隠すのではなく、「全部ルールブックのダイス計算通りに動かしているので、納得いかないならPDFを読んで確率を計算してください」という開発元の姿勢。セクション7のオープンイシュー「御者・馬丁のプロ値と影響度・目星判定の食い違い」に対する一つの答え方でもある——数値自体は公開するが、その解釈は依然としてプレイヤーに委ねられる（セクション5-1の「無機質な数値化を避ける」方針とは、数値の公開・非公開ではなく物語化の有無で両立する）
- デジタルでのソロプレイと、印刷して友人と卓を囲むTRPGセッションの両方が同じ製品で楽しめる、一石二鳥の仕様
- **キャラシ出力機能**：CRPG側で育てたキャラクター（辺境伯まで栄達したキャラクター等、セクション10-3-2の栄達ルートの成果を含む）を、TRPG用キャラクターシート形式（PDF）でエクスポートできる機能。CRPGで積み上げた実績（プロ値・影響度・爵位等）がそのままTRPGの判定基準としてGMの手に渡り、セッションのNPCやPCとして持ち込める。栄達ルートの「実務・実績を第三者が評価する」という一貫した設計思想の、プレイヤー体験としての一つの到達点になる
- 総ページ数「350ページ」という具体的な数字も示され、既存メモの「無駄に精緻」路線が物理的なページ数として可視化される表現として言及された

**リリースタイミング（両論併記）**：
- **1周年記念での追加案**：発売と同時にではなく、CRPG本編が軌道に乗った後の記念コンテンツとして位置づける。急いで同梱する必要はないという考え方
- **発売時から同梱していてもおかしくない案**：Glyphfall本編の完成までには長い開発期間がかかる見込みであるため、その間に設計文書（このaddendumや`daggerfall_dq_world_generation_spec.md`）自体がTRPGルールブックとして先に固まっている可能性が高い。むしろ「本編が完成する前にTRPG版の方が先にできている」という順序が自然、という見方。この場合はGeminiちゃんの案（Steamインストール時から同梱）に近い形になる
- 両案とも未決のまま記録。実際の判断は開発の進行状況（本編とTRPG版設計文書、どちらが先に完成に近づくか）次第

### GM's Guide別売り構想

基本ルールブック（プレイヤー向け）の本体同梱に対し、GM向け書籍は別売りにするという案。実在のTRPG（D&D等）における「プレイヤーズハンドブック（本編相当）」と「GM's Guide（別売り）」の分離という商習慣をそのまま踏襲する。

- **収益構造としての妥当性**：プレイヤー用の基本ルール（判定方法、キャラシ、栄達ルートの表面的なルール）は本編同梱で無償提供。「裏側の仕掛け」（モンスターの真の弱点、殺人教団の正体、辺境伯領地経営の隠し要素、古代文明の真相）はGM専用書籍として別売りにする構造
- **既存の隠しパラメータ思想との接続**：セクション6-4の`hiddenParameters`（`hidden` / `appraisable` / `visible`の三段階可視性）が、メタなレベルで「プレイヤー向け情報／GM向け機密情報」という区分に昇格する。GM's Guideそのものが、ゲーム全体でいちばん大きな`hiddenParameters`として機能する
- **DLC群との統合**：セクション10-3の「本当はヤバい古代文明」「突撃！隣のダークファンタジー」のようなダーク系サプリメント群は、実質的にGM's Guideの分冊として位置づけ直せる。プレイヤーは読む必要がなく、GMだけが知っていて小出しに使う「ネタ帳」という体裁が、既存の「本編は軽め、重い裏設定はDLC」の方針とそのまま重なる
- **商業的な皮肉としての側面**：実在のTRPG業界には「基本ルールブックだけでは不完全で、追加の設定資料集・上級ルール集を延々と買わせる」という商業的な側面があり、それを自虐的に取り込む案。「Glyphfall GM's Guide（追加料金）」と称しつつ、実は本編の隠し要素を全部解説してしまう、というメタなネタバレ商法として位置づけられる

# 11. 開発方針：基本システム優先とMVPの必要性

セクション8〜10でDLC・サプリメント構想が大きく広がった一方、「たずねる」「成長システム」のような日常的に触れる基本システムの検討がまだ薄い、という気づきが出た。DLC群はいずれも本編の基本システムがあってこそ活きる拡張であり、順序としては基本システムの決定を先に済ませるべきという方向性を確認した。

## 11-1. 基本システムの検討状況の棚卸し

- 会話・知識（「はなす」「たずねる」、話題ウィンドウ、隠しパラメータ）：セクション1・1-1でかなり具体的な会話サンプルまで検討が進んでいる
- 移動・休息（馬車・御者・馬丁、耐久度）：セクション2で経済構造まで検討済み
- 成長（スキル・レベル）：セクション2-5で方向性（Learn by Doing＋休息必須レベル制の二層構造）は決まったが、詳細な数値設計・UIはこれから
- 戦闘・探索：現時点でほぼ未着手。基本システムの中でも最も手薄な領域として認識しておく

## 11-2. 早期にMVP（最小限の遊べる環境）を作る方針

紙の上の議論だけでは、「たずねる→はなす→覚える」のループが実際に触って気持ちいいかどうかは判断しづらい。セクション10-4で出ていた「TRPGとして一度動かしてみる（実装前のバグ出し・面白さの検証）」というアイデアとも通じる発想として、CRPGとしての本実装より前に、ごく小さなプロトタイプで基本システムを触ってみる方針を検討した。

想定される最小構成：

- 「たずねる」システム（階層メニュー、または1-1で出たカードUI案）
- 話題ウィンドウ／覚える
- 隠しパラメータを1〜2種類だけ（影響度のみ、など）

これをテキストベースの簡易プロトタイプ、または簡単なWebページ程度の実装で先に動かし、会話システムの「触り心地」を検証してから、移動・成長・戦闘などの他システムや、DLC構想の細部（セクション8〜10）に着手する、という優先順位が現実的ではないかという方向性で一致した。
