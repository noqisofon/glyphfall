# Daggerfall × ドラクエ 世界生成仕様

本ドキュメントは、世界設定（`eraPreset`／`stylePreset`／ギルド構成／隠しパラメータの可視化／亜人種族など）のルール・データ構造を定義する仕様書。デザイン上の狙いや議論の経緯は `daggerfall_dq_memo_addendum.docx` のセクション6を参照。本書は「ルールとデータ」を随時更新していく前提のリファレンスとして、コンセプト文書側から分離している。

## 0. 設計原則

- 世界設定は「国 → 地域 → 町」の階層構造で継承・上書きされる。下位階層の指定がなければ上位の値を継承する
- すべての項目は `eraPreset` / `stylePreset` の既定値テーブルに初期値を持ち、世界設定ファイルには既定値からの差分（上書き分）のみを保存する（差分保存方式）
- 前方互換性：知らないキーは無視し、デフォルト値にフォールバックする。`formatVersion` を必須フィールドとする
- 難易度は無機質な数値調整ではなく「世界観としての個性」として設計する（プリセット名は世界観を含めた名前にする）

## 1. `eraPreset`（時代プリセット）

史実のヨーロッパ史をベースにした4段階。時代が進むほど制度・インフラが整い、移動宮廷から定住・官僚制国家へ、ギルドが未成立の状態から協会型の新興組織が進出する状態へ変化する。

全時代を通じてモンスターの存在を前提とし、「移動宮廷＝巡回討伐を兼ねた武装集団」「街道の安全＝王権の正統性の指標」という読み替えにより、史実の統治形態とモンスター脅威度を矛盾なく両立させる。

### 既定値テーブル

| 項目 | early_medieval | high_medieval | late_medieval | renaissance |
|---|---|---|---|---|
| 権力の形 | 移動宮廷・封建 | 都市の勃興 | 都市の成熟・疫病後 | 商人・銀行・パトロン |
| 識字率 (`literacyRate`) | 極低（聖職者のみ） | 低 | 中 | 中〜高（印刷術） |
| 書類読解スキル取得 | 稀少（要投資） | 選択科目 | 選択科目 | 標準寄り |
| 治安 (`security`) | 低 | 低〜中 | 中（傭兵が荒らす） | 中〜高（都市内） |
| 街道・インフラ | 荒れ果てている | 巡礼路・市街道のみ | 整備されるが疫病で寸断 | 整備・為替網あり |
| ギルド構成既定 (`guildStructureDefault`) | ほぼ無し（修道院・領主館が代替） | 統合型が多い | 分離型が増える | 分離型＋協会型が進出 |
| 通貨 | 現物・地域貨幣が混在 | 地域貨幣、両替商が台頭 | 複数貨幣＋比価変動 | 為替・銀行券 |
| 度量衡 | 町ごとにバラバラ | 町ごとにバラバラ | 一部統一の動き | 換算表が普及 |
| `hiddenParameters` 既定 | 全項目 `hidden` 寄り | 同左 | 同左 | 査定書等で一部 `appraisable` |
| 契約書のプロ値記載 | 存在しない（口約束） | 一部ギルドのみ | ギルド発行が主流 | 標準・偽造も横行 |
| 耐久度の減りやすさ | 極めて高 | 高 | 中 | 中 |
| 旅の摩擦（地域差） | 大（言語・通貨・法がバラバラ） | 大 | 中 | 中（提携網で緩和） |

## 2. `stylePreset`（様式プリセット）

時代を選ばない、様式そのものを選ぶ軸。`eraPreset` とは独立したキーであり、任意の組み合わせが可能（例：`high_medieval` ＋ `narrowpa` ＝ 史実の統治形態だが利便性は高い世界）。

### 2-1. 公式プリセット

- **`narrowpa`**：由来は「なろう＋ヨーロッパ」（通称ナーロッパ）。綴りは英単語 narrow（狭い＝画一的）にも読める語呂合わせ。時代考証を気にせず、ゲーム的な利便性が世界の常識になっている状態
  - 既定値：識字率＝高、書類読解スキル＝ノーコスト取得済み、治安＝高、インフラ＝整備済み・耐久度減りにくい、ギルド構成＝三者統合が標準、通貨＝金銀銅の3種で統一、`hiddenParameters`＝`visible` 寄り、亜人＝`common`（主要種族が揃っている）
- **`historical_fantasy`**（イバラギーッパ、仮称）：史実のリアリティとファンタジー要素を融合させた折衷様式。`narrowpa` とは方向性が逆で、史実の重みと不便さを残しつつ、モンスターや魔法を社会構造に無理なく組み込む
  - 既定値：`eraPreset` の既定値をそのまま踏襲（上書きなし）、亜人＝`none`（モンスターのみ）が自然な既定

### 2-2. ユーザー定義様式

- プリセットと同じ構造（識字率・ギルド構成・インフラ等の既定値セット）を持つオブジェクトとして保存・共有可能
- 地方名ミーム（「サイタマーッパ」「トチギーッパ」等）が自然発生する余地を想定した設計とする
- 保存フォーマットの詳細は未決（オープンイシュー、addendumセクション7参照）

## 3. ギルド構成（`guildStructureDefault` / 町ごとの `guildMerges`）

宿屋ギルド・酒場ギルド・冒険者ギルド（または冒険者協会）の統合／分離パターン。

### 3-1. 類型

| 類型 | 説明 |
|---|---|
| 三者統合型 | 一つの看板で宿・酒場・依頼所を兼ねる（辺境・小都市向け） |
| 宿屋＋酒場のみ統合 | 「もてなし業ギルド」。冒険者組織とは別 |
| 酒場＋冒険者のみ統合 | 依頼は酒場で受ける伝統。宿屋ギルドは距離を置く |
| 完全分離型 | 職能が細分化され、縄張り・利権が明確（大都市向け） |
| 協会提携型 | 広域組織の冒険者「協会」が、各地の宿屋・酒場ギルドと個別に提携契約を結ぶ |

ギルド（地域・職能の自治組織）と協会（広域・任意加入の連合）は制度として別物であり、両者の新旧対立を物語要素として利用できる。

### 3-2. 決定に使う入力パラメータ

- 人口・町の規模（小さいほど統合型になりやすい）
- 街道上の位置（隊商・冒険者の往来があるか）
- モンスター脅威度（高いほど冒険者組織が強く、酒場・宿と癒着しやすい）
- 国の政体（都市共和国は分離型で利権化、王権国家は統制、帝国は緩い）
- 協会進出の歴史的経緯

### 3-3. データ構造

```json
"guildMerges": [["inn", "tavern"]]
```

統合グループのリストとして持たせることで、統合・分離・提携のすべてのパターンを同じ形で表現する。協会提携は別フィールド（`affiliation`）で表現する。

```json
"affiliation": { "association": "adventurers_guild_union", "type": "affiliated" }
```

## 4. `hiddenParameters`（隠しパラメータの可視化）

耐久度・影響度・プロフェッショナル値など、隠しパラメータの見え方を世界設定から一括制御する。

| 値 | 意味 |
|---|---|
| `hidden` | 判定（目星・魔術の知識等）でしか分からない |
| `appraisable` | 鑑定・ギルド査定など第三者経由で分かる |
| `visible` | ステータスとして直接見える |

対象キー：`influence`（影響度）、`durability`（馬車等の耐久度）、`professionalValue`（御者・馬丁等のプロ値）。今後、対応する隠しパラメータが増えるごとにキーを追加する。

## 5. `demihumans`（亜人種族）

| フィールド | 値 |
|---|---|
| `presence` | `none`（なし）／`few`（少数・伝説や辺境のみ）／`common`（一般的） |
| `relation` | `coexist`（共存）／`segregated`（棲み分け）／`hostile`（敵対） |
| `races` | オブジェクト配列。`{ "id": "elf" }` 等 |

`races` は将来の特性定義（`traits`：寿命、得意分野、種族間関係、社会構造、影響度への補正等）を見据え、当初から文字列リストではなくオブジェクト配列として持たせる。`traits` の具体設計は未着手（オープンイシュー）。

## 6. 独立項目（プリセット非連動）

時代・様式のいずれにも連動させず、`settings` 内に個別項目として持つ。世界の「味付け」枠。

- `damselEventFrequency`（苦難の乙女発生率）：初期値 `medium`
- 今後の追加候補：仲間運の難易度、山賊のリポップ挙動 等

## 7. 世界設定JSON全体構造（フル展開イメージ）

実際の保存ファイルは差分形式（0節参照）。以下は `eraPreset` / `stylePreset` の既定値を全て明示した場合の構造イメージ。

```json
{
  "formatVersion": 1,
  "worldName": "…",
  "summary": "…",
  "tags": [],
  "eraPreset": "high_medieval",
  "stylePreset": "historical_fantasy",
  "settings": {
    "literacyRate": "low",
    "guildStructureDefault": "merged_inn_tavern",
    "infrastructureDurability": "fragile",
    "damselEventFrequency": "medium"
  },
  "hiddenParameters": {
    "influence": "hidden",
    "durability": "appraisable",
    "professionalValue": "appraisable"
  },
  "demihumans": {
    "presence": "few",
    "relation": "segregated",
    "races": [
      { "id": "elf" },
      { "id": "dwarf" }
    ]
  },
  "seed": "a3f9c2",
  "derivedFrom": null
}
```
