# ADR-0024: 街道（旅シミュ）と地下迷宮のハイブリッドエンカウント方式の採用

- Status: Accepted
- Date: 2026-09-17

## Background

ADR-0004およびADR-0013において、街道移動は「旅シミュレーション」として移動姿勢（慎重に／普通に／大胆に）に応じた確率抽選と突発イベント（山賊の襲撃、野獣との遭遇等）によるランダムエンカウント方式が確立された。
一方、王都南東の「封魔の地下迷宮」（ADR-0010, ADR-0017, ADR-0021）では、セルオートマトン法によるCave生成の床マス上に `TileType::MonsterSymbol`（魔物シンボル）が配置され、接触することで戦闘に突入する仕組みが試験的に導入されていた。

しかし、ダンジョン探索におけるエンカウント方針（完全ランダムエンカウントなのか、シンボルエンカウントなのか）が仕様として確定しておらず、魔物シンボルを倒した後もマップ上にシンボルが残り続け、再度踏み込もうとすると無限に戦闘が再発して通路が塞がれるという不整合が生じていた。

## Circumstances

地下迷宮におけるエンカウント方式の設計について、以下の選択肢を検討した：

1. **完全ランダムエンカウント（古典DQスタイル）**:
   - 一歩歩くごとに一定確率で戦闘が発生する方式。
   - JRPGとしての伝統的なリソース削り・予測不能な緊張感がある一方、せっかく実装された松明（`[L]`キー）による視界制限（FOV）やドット絵の魔物シンボルを活用できなくなる。
2. **徘徊シンボルエンカウント（ローグライク／近年のJRPGスタイル）**:
   - プレイヤーの移動に合わせて魔物シンボルがマップ上を追尾・徘徊する方式。
   - 非常にゲーム性が高いが、現行のターン制移動・フォロワー追従アーキテクチャに対して魔物の経路探索（Pathfinding）や移動調停システムを新設する必要があり、初期実装としてのコストと複雑度が高い。
3. **ハイブリッド方式（街道＝ランダム旅シミュ、迷宮＝固定シンボルエンカウント）**:
   - 街道は移動姿勢による確率的な旅シミュレーションを継続。
   - 地下迷宮はマップ上に固定配置された魔物シンボルに接触して戦闘に入るシンボルエンカウントを採用。
   - 徘徊AIは将来の拡張課題とし、当面は「暗闇の中に潜む見張り・番人」としての固定シンボルとする。戦闘勝利時にはそのシンボルを床タイルへ置換（消去）して通路を開通させる。

## Rationale

「Daggerfall × DQ」のハイブリッドコンセプト（ADR-0001）において、地下迷宮の最大の魅力は「暗闇と松明による視界制限（FOV）」である。
暗闇の先（視界の縁）にうっすらと魔物の影が見えたとき、「松明を灯して先制するか」「戦力を温存するために別ルートへ迂回するか」という索敵・ダンジョンハックの面白さは、シンボルエンカウントによってこそ真価を発揮する。

また、街道（見晴らしの良い広域移動）は「大まかな旅の姿勢と偶発的トラブル」というDaggerfall的旅シミュレーション（ADR-0004）が適しているのに対し、地下迷宮（閉鎖空間のダンジョンハック）は空間把握と位置取りが重視されるため、両者の性質の違いに合わせたハイブリッド構成が最も自然である。

徘徊シンボルについては魅力的なアイデアであるものの、まずは「接触して戦闘に入り、倒せば道が開通する」という固定シンボルの基本サイクルを完成させることが優先される。

## Decision

街道と地下迷宮で異なるエンカウントモデルを組み合わせる「ハイブリッドエンカウント方式」を採用する：

1. **街道（地上）**:
   - 移動姿勢（Cautious / Normal / Bold）による基礎確率抽選および突発イベントエンジン（ADR-0013）に基づくランダムエンカウントを継続する。
2. **地下迷宮（封魔の地下迷宮 各階）**:
   - 固定配置された `TileType::MonsterSymbol` によるシンボルエンカウントを採用する。
   - プレイヤーが魔物シンボルのマスへ移動を試みた際、プレイヤーはその手前に留まり、不意打ち戦闘（`MoveOutcome::TriggerBattle`）が発生する。
   - `MoveOutcome::TriggerBattle` には接触した魔物シンボルの座標（`monster_pos`）を付与し、`TownState` に記録する。
   - 戦闘に勝利した場合、記録された座標の `MonsterSymbol` を `TileType::DungeonFloor`（通常のダンジョン床）に置換してシンボルを消去し、通路を開通させる。
   - 戦闘から逃走した場合、または敗北した場合は、シンボルは消去されずそのまま残る。
3. **将来の拡張（Consequences）**:
   - プレイヤーの移動に合わせた魔物シンボルの徘徊・追尾AIや、松明の点消灯による索敵・ステルス要素（スニーク）は、本決定の固定シンボル基盤の上に将来のADRとして段階的に拡張する。
