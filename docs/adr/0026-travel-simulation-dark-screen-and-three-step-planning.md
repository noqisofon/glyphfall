# ADR-0026: 街道旅シミュレーションの暗転演出と3段階旅計画（移動先×姿勢×手段）の採用

- Status: Proposed
- Date: 2026-09-19

## Background

ADR-0004において、Glyphfallのファストトラベル（FT）は単純な瞬間移動（ワープ）ではなく、時間経過・危険・サバイバル感を伴う「旅シミュレーション」として定義された。
そこでは移動姿勢（慎重に／普通に／大胆に）による移動時間とエンカウント率のトレードオフが提示され、ADR-0013において突発イベントの2段階抽選エンジン（基礎確率ロール＋履歴・重み付き抽出）が設計された。

しかし、既存の実装は街道口に接触した際に画面上部ステータスバー上で移動姿勢を選ぶのみにとどまり、移動先は「すずかけ村」に固定、決定した瞬間に暗転も経過演出もなく一瞬で村マップにワープしていた。そのため、プレイヤーが「町と町の間を旅している」という旅情やサバイバル感を実感しにくく、突発イベントとの視覚的・体験的な接続も未完成のままとなっていた。

## Circumstances

街道移動の肉付けを行うにあたり、以下の2つの論点を検討した。

### 1. ファストトラベル中の画面演出（リアルタイム歩行 vs 暗転テキスト送り）

- **Option A: ミニマップ上リアルタイム歩行方式**
  広域街道マップを用意し、パーティシンボルが目的地まで自動で歩行する方式。
  視覚的な位置関係は掴みやすいが、広大な街道マップのタイルグラフィック制作コストが高く、見晴らしの良い屋外では「暗闇と松明による視界制限」という本作の魅力が薄れてしまう。
- **Option B: 暗転テキスト送り方式（採用）**
  画面を暗転（黒背景）させ、中央にDQ風・ターミナル風のテキスト送りで旅の経過日数や情景（「1日目: 街道沿いの森を進む」「冷たい雨が降り始めた」）を表示する方式。
  グラフィック負荷を最小限に抑えつつ、プレイヤーの想像力を刺激して「遠く離れた町への過酷な旅路程」を演出できる。突発イベント発生時も、暗転画面上にイベント文章（将来的なスチール絵／カットイン画像を含む）と選択肢を表示し、戦闘や会話へシームレスに接続できる。

### 2. 旅計画の入力粒度と移動手段（徒歩／馬／馬車）の扱い

街道口でプレイヤーが何を決定するかについて、単一の姿勢選択ではなく「①移動先 → ②移動姿勢 → ③移動手段」という3段階の旅計画ステップを設けることとした。

ここで、「移動手段（徒歩／馬／馬車）」の世界観上の位置づけについて以下の課題が挙がった：
- 本来のリアルな世界観設計としては、「町の外へ直接歩き出そうとすれば、当然ながら徒歩でしか出られない」はずである。
- 馬に乗るなら町外れの厩舎（馬借り所）、馬車を利用するなら駅馬車の停留所（駅）といった物理的なインフラ拠点が町の中に存在し、そこで手配して乗るのが自然である。
- しかし、現時点で町外れの駅や厩舎、NPCインタラクトをすべて作り終えるまで街道旅シミュレーションの着手を待つのは、開発の手戻りや機能検証の遅延を招く。

## Rationale

- **暗転テキスト送り演出の採用理由**:
  Daggerfallが持つ「旅の計画を立て、その結果としての時間・出来事を噛み締める」というコンセプトを、本作のレトロターミナル／罫線UIスタイルで最も効果的に表現できるため。移動中の画面をあえて暗転にすることで、プレイヤーは「一瞬で着いた」のではなく「暗闇の街道を何日も旅してきた」という時間感覚を得られる。また、突発イベント発生時のテキスト提示や、将来的なドット絵スチール（街道の野営地、立ち塞がる山賊の影など）を中央に表示する拡張スロットとしても極めて親和性が高い。
- **移動手段選択の二段階移行方針**:
  現段階（プロトタイプ）では、街道口での旅計画UIの第3ステップとして「徒歩／馬／馬車」を直接選択可能とし、移動手段ごとの計算（移動日数、レンタル・運賃フォリン、馬車耐久度減衰、イベント遭遇率の差異）のロジック検証を最優先する。
  そして将来的には、街の通常の出入口からは「徒歩」固定で出発し、町外れの厩舎（馬借り所）や駅馬車停留所（駅）から出発する場合にのみ「馬」「馬車」での旅シミュレーションが起動する、という物理的な拠点配置へスムーズに移行できる設計とする。共通の旅計画パラメータ構造（`TravelPlan`）を持たせることで、呼び出し元が街道口UIであっても駅のNPCであっても同じシミュレーションパイプラインを実行できる。

## Decision

1. **暗転演出型ファストトラベルの採用**:
   - 街の外へ出る移動が確定した際、画面を暗転（黒背景）させ、旅シミュレーション演出モードへ遷移する。
   - 暗転中の中央ウィンドウに、経過日数・旅の情景メッセージ（天候、地形、野宿の様子など）を一定時間間隔またはキー送り（Space/Enter）で表示する。
   - 突発イベント発生時は暗転画面上にイベントメッセージを表示し、選択肢（戦う／避ける／交渉など）を提示する。戦闘突入時はそのまま戦闘画面へ移行し、戦闘終了後に暗転旅画面へ復帰する。
   - 将来的な拡張として、イベント発生時に暗転画面中央へスチール画像（カットイン・ドット絵イラスト）を描画できるスロットを確保する。
   - 目的地に到着すると、暗転が明けて目的地のスポーン位置（すずかけ村、または王都）へ復帰する。

2. **旅計画の3段階選択UIフロー**:
   - 街の出入口（街道口）に接触した際、画面を専用の旅計画パネル（3段階選択）へ遷移させる：
     - **Step 1: 移動先 (Destination)**: 行き先を選択（当面は「すずかけ村」一択、将来的に複数拠点へ拡張）。
     - **Step 2: 移動姿勢 (Posture)**: 慎重に（低リスク・長旅）／普通に（標準）／大胆に（高リスク・短時間・急行）。
     - **Step 3: 移動手段 (Means / Transport)**: 徒歩（無料・標準速度）／馬（有料・高速・少人数）／馬車（高額運賃・大人数・荷物可・耐久度消費）。

3. **移動手段の仕様と段階的移行**:
   - 当面の実装では、街道口での旅計画UI内で直接3種の移動手段を選択可能とする。
   - 各移動手段の基準値：
     - **徒歩**: 費用 0G、基準所要日数（例: 3日）、イベント基礎確率 1.0倍
     - **馬**: 費用 40G、基準所要日数を短縮（例: 1日）、イベント基礎確率 0.8倍
     - **馬車**: 費用 80G、基準所要日数（例: 2日）、イベント基礎確率 1.2倍（目立つため山賊に狙われやすい）、馬車耐久度の減衰（ADR-0025）
   - 将来的に町外れに「馬借り所（厩舎）」や「駅馬車停留所（駅）」を実装した際は、街道口の直接選択は徒歩のみに限定し、馬や馬車は各インフラ施設から発車する形式へ移行する。

4. **データ構造とロジック（`glyphfall-core`）**:
   - `core/src/event/` または `core/src/town/` に、旅計画およびシミュレーション状態を配置：
     - `TravelTransport`: `Foot`, `Horse`, `Carriage` のEnum定義
     - `TravelPlan`: 移動先、移動姿勢、移動手段をまとめた構造体
     - `TravelSimulationState`: 現在の旅程日数、残り日数、発生済みイベント、暗転メッセージキューなどを管理するステートマシン

## Consequences（任意）

- 移動中に暗転画面とメッセージ送りが入ることで、瞬間移動感が解消され、世界地図の広がりと過酷さを体感できるようになる。
- ADR-0013の突発イベント抽選エンジンおよびADR-0025の世界観プリセット（治安、馬車耐久度減衰率など）が、この暗転シミュレーションの中で実際に機能し始める。
