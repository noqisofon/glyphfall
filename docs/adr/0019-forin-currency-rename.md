# ADR-0019: ゲーム内通貨名を「フォリン」に変更

- Status: Accepted
- Date: 2026-09-16

## Background

現状のゲーム内通貨は「ゴールド（Gold / G）」という汎用名で、`glyphfall-core`の
`Inventory::gold`フィールドをはじめ、ショップ・宿屋・宝箱・UI表示のメッセージ文言に
直書きされている。ADR-0001で採用したDaggerfall×DQハイブリッドの世界観
（王都アルカンを擁する独自の中世欧風ファンタジー世界）に対して、「ゴールド」という
名称はどの実在RPGにもある没個性な語であり、この世界固有の生活感・経済感を
何も語らない。

## Circumstances

通貨の呼称を世界観に根差した固有名詞に差し替える案として「フォリン」が挙がった。
これはハンガリーの実在通貨「フォリント（forint）」をもじったもので、ゲーム内では
銀貨として位置づける想定。調べたところ、フォリント自体の語源は中世欧州の銀貨
「フローリン（florin）」に遡ることが分かった。つまりカタカナ表記「フォリン」は
フォリント風の響きとフローリン（実在した銀貨）の両方に掛かる二重の裏付けを持ち、
「銀貨」という設定とも矛盾しない。

他に検討した候補：
- ターレル/ターラー（Thaler） — 「ドル」の語源となった大型銀貨。銀貨としての
  裏付けは最も強いが、語感が硬く現行のカジュアルな文体と噛み合わない
- グルデン（Gulden）、クローネ（Krone）、デナリ（Denarius）
  — いずれも実在通貨のもじりとしては妥当だが、フォリンほど響きの軽さと
  据わりの良さを両立しない

## Rationale

- フォリン／フォリント／フローリンの三重の掛かりにより、単なる思いつきの
  響きではなく語源的な裏付けを持たせられる
- 「銀貨」という設定は、今後の経済システム（銅貨・金貨など複数通貨単位の
  導入）を見据えた拡張の余地を残す
- 表記・略称は既存の「G」表記を踏襲し、影響範囲を名称のみに限定する
  （`inv.gold`等のAPI名を含めた全面リネームは本ADRの範囲外とし、
  別途実装時に判断する）

## Decision

ゲーム内通貨の名称を「ゴールド」から「フォリン」に変更する。位置づけは銀貨とする。
UI・会話文言上の表示は「フォリン」（略称「G」は当面維持）に置き換える。
`Inventory::gold`などの内部API名・変数名のリネームは本ADRでは決定せず、
実装着手時に必要性を判断する。
