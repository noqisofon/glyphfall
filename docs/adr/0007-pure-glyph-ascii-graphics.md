# ADR-0007: グラフィック方針としてピュア・グリフ／ASCIIアート表現の採用

- Status: Superseded by [ADR-0009](0009-retro-2d-sprite-graphics.md)
- Date: 2026-09-13

## Background

本作『Glyphfall』は、「Daggerfall × ドラクエ」という膨大なシミュレーション濃度と親しみやすさを融合する野心的なプロジェクトである。
しかし、グラフィック表現としてリッチな3Dグラフィックや大量のドット絵（ピクセルアート）を採用すると、アセット調達・制作のコストが跳ね上がり、プロシージャル生成（手続き型による無数の町、モンスター、ダンジョンの生成）というコアの強みが阻害される懸念があった。

## Circumstances

グラフィックの表現形式について、以下の4つの方向性を検討した：

1. **ピュア・グリフ／ASCIIアート路線**: モンスター、マップ、オブジェクトを文字・記号・罫線のみで描く（Cogmind, Stone Story RPG, Rogue風）。
2. **ワイヤーフレーム／疑似3Dグリフ路線**: 一人称視点の迷宮をラインや罫線の遠近法で描く（初代Wizardry風）。
3. **レトロドット絵ハイブリッド路線**: 枠線はターミナル風で、モンスターのみ粗いドット絵を差し込む（PC-98 / 初代DQ風）。
4. **CRTサイバーターミナル特化路線**: ビジュアル自体は最小限とし、スキャンラインやグロー演出に特化する。

## Rationale

検討の結果、方向性1（ピュア・グリフ／ASCIIアート路線）を採用するのが最も合理的かつ魅力的であると判断した。

判断基準は以下の通り：
1. **プロジェクト名との完全な整合性**:
   社内コードネーム「Glyphfall（罫線文字＝グリフ + Daggerfall）」のコンセプトそのものであり、独自の強力な美学とアイデンティティを確立できる。
2. **アセット制作コストの最小化**:
   画像ファイルや3Dモデルの制作が一切不要となり、テキスト定義だけで新しいモンスターやNPC、ダンジョンを量産・プロシージャル生成できる。
3. **等幅ターミナルUIとの親和性**:
   すでに構築した Bevy ECS の罫線グリッドレイアウトや緑モノクロパレットと自然に融合し、統一感のある画面を構成できる。
4. **想像力の余白**:
   文字記号だからこそ、プレイヤー自身の脳内でディテールが補完され、TRPGやクラシックcRPG特有の「世界に没入する感覚」を呼び起こす。

## Decision

本作のグラフィック表現として「ピュア・グリフ／ASCIIアート路線」を採用する。
モンスターの戦闘グラフィック、フィールド・ダンジョンの視覚情報、エフェクトを等幅フォントの文字・記号（Unicode/ASCII）の組み合わせによって表現する。
