# ADR-0022: 素性（出自）システムによるゲーム開始パターンの統一

- Status: Accepted
- Date: 2026-09-17

## Background

Glyphfallでは既に、三分割会話UIと手動キーワード記憶（ADR-0002）、隠しパラメータ「影響度」によるパーティ自律行動制御（ADR-0003）、旅シミュレーション型ファストトラベルと創発イベント（ADR-0004）、主人公の非英雄性（パンピー）と勇者キャンペーンの分離（ADR-0005）といった、ゲームの中盤以降を支える主要システムがADR化済みである。

しかし、それらのシステムに「プレイヤーがどう物語に入るか」——ゲーム開始時点の状況そのもの——を接続する設計はまだ存在しなかった。キャラクリを終えた直後、プレイヤーがどんな状況に置かれ、何を最初に習熟させられるのかという「入口」の部分が手つかずだった。

比較対象として本家『Daggerfall』の始まり方を確認した。キャラクリ後に難破・遭難の状況説明が入り、理不尽な難易度のチュートリアルダンジョン（Privateer's Hold）を突破することで初めて世界が開放される、という「戦闘の心構えを叩き込む」構造になっている。Glyphfallは戦闘力ではなく「はなす／覚える」という情報収集の作法を主眼に据えているため、オープニングが担うべき機能はDaggerfallのそれとちょうど裏返しになるはずだ、という着想が今回の検討の出発点になった。

## Circumstances

ゲーム開始パターンの設計として、以下の順で選択肢を検討した。

1. **マトリクス案（最初に出た案）**: 「①誰として始まるか（パンピー／勇者）× ②どの世界に始まるか（新規／共有／継承）× ③どう始まるか（転生／行き倒れ／通常）」という3軸の組み合わせでゲーム開始パターンを分類する案。軸を独立に組み合わせる分、パターン数は多く作れるが、各軸の意味が開始直後の体験と直結しにくく、「①×②×③」の組み合わせごとに個別の初期状況・初期所持品を設計し直す必要が出てしまう。
2. **素性（出自）ベース案への収束**: マトリクス案を検討する過程で、「キャラクリで選ぶ出自（素性）そのものが、オープニングの状況・初期所持品・最初に習熟させられるシステムを規定する」という切り口に収束した。素性一本の選択で開始状況が一意に決まるため、マトリクス案より単純でありながら、各素性ごとに固有の体験を作り込める。

素性の一覧は経済・武力・知識・没落／底辺の4系統で洗い出し、暫定14種とした（詳細はDecisionを参照）。

このうち「駆け落ち者」を深掘りした。他の素性がすべて単独スタートであるのに対し、駆け落ち者は最初から「二人」で始まる特殊な素性である。ここで駆け落ち相手の扱いについて2案を比較した。

- **選択式・固定案**: 駆け落ち相手をキャラクリ時に確定した1人として提示する。実装は単純だが、相手のバリエーションが薄く、幼馴染システム（ADR-0005）が持つ「確定ではないランダム性」の面白みと噛み合わない。
- **プール制案**: 幼馴染チェックON時は幼馴染＋プロシージャル生成2〜3人（計3〜4人）のプールから選ぶ。幼馴染以外のメンバーのみリロール可能（上限3回）とする。ランダム性と選択の余地を両立できる。

プール制を採用することとした。

さらに、駆け落ち者と対になる素性として「探し人（誰かを探して旅をしている人）」を新規に検討した。探索対象の扱いについても2案を比較した。

- **選択式（最初から分かる）案**: キャラクリ時点で探し人の正体（名前・関係・特徴）を確定して提示する。プレイヤーは最初から目的が明確になるが、既存の「はなす／覚える」システムが持つ、話題を集めて手繰り寄せる過程そのものの旨味が薄れてしまう。
- **後から分かる方式**: 探索対象の詳細は伏せたまま開始し、道中で「はなす／覚える」を通じて手がかりを集めて初めて判明する。既存の隠しパラメータ思想（影響度・耐久度・プロ値をいずれもマスクデータとして扱う既存ADRの方針）と一貫する。ただし完全ノーヒントでは詰みうるため、素性由来の固定トピックとして「人を探している→○○（名前）」という断片情報だけはキャラクリ時点で開示する。

後から分かる方式を採用することとした。

この会話フローを具体化する過程で、既存のマンティコア関所の語順ルール（ADR-0012で言及した、衛兵の発言のように起点となる単語が文脈を決める既存の話題ディスパッチ仕様）を拡張し、覚えた単語同士を組み合わせて尋ねる「複合フレーズでたずねる」という汎用システム案が派生した（例：○○＋最後に見た場所、を組み合わせて尋ねる）。

## Rationale

素性を軸に据えた理由は、その素性が「最初にどのシステムを叩き込むか」というチュートリアル分岐として機能させたかったためである。Daggerfallが単一の戦闘チュートリアルダンジョンで全プレイヤーに同じ心構えを叩き込むのに対し、Glyphfallでは素性ごとに異なる初期状況を与えることで、プレイヤーが最初に触れるシステム（交渉、金策、逃走、探索など）を分散させられる。

探し人の探索対象を「後から判明」方式にしたのは、既存の隠しパラメータ思想（影響度＝ADR-0003、および同列に扱われる耐久度・プロ値）との一貫性を優先したためである。選択式にして最初から探索対象を開示してしまうと、「はなす／覚える」システムが持つ、断片情報を集めて手繰り寄せる過程そのものの価値が薄れると判断した。

駆け落ち者の初期影響度を高め（既存の影響度システムの自然上限88〜89に近い値）に設定する理由は、関係性の初期値が高いこと自体が、「高い影響度＝必ず従うわけではない」という既存ルール（ADR-0003）の緊張感を強調する題材として機能するためである。最初から高い信頼関係にある相手が、それでも土壇場で意に従わないかもしれない、という構造を駆け落ち者という素性で体現させたい。

リロール上限を3回とした点については、セッション中に明確な理論的根拠は出ていない。「3回くらいでいいのでは」という軽い決定であり、ここは正直にそう書いておく。ADR-0000の思想（軽い決定を過大評価しないための正直さ）に沿えば、この数値は今後の調整で変わりうる仮の値として扱ってよい。

## Decision

1. ゲーム開始パターンは、キャラクリで選択する「素性（出自）システム」として統一的に扱う。マトリクス的な軸の組み合わせでは表現しない。
2. 素性一覧を以下の4系統・暫定14種として定める。ただし商人の息子・駆け落ち者・探し人以外の詳細はまだ深掘りしておらず、今後の検討課題とする（Circumstances節参照）。
   - **経済系**: 商人の息子、ほか（詳細未検討）
   - **武力系**: 傭兵崩れ、ほか（詳細未検討）
   - **知識系**: 元神官見習い、ほか（詳細未検討）
   - **没落／底辺系**: 農家の三男坊、孤児院育ち、ほか（詳細未検討）
   - **特殊（複数人開始）**: 駆け落ち者、探し人
3. **駆け落ち者**: 駆け落ち相手はプール制で選択する。幼馴染チェックON時は幼馴染＋プロシージャル生成2〜3人（計3〜4人）のプールを提示し、幼馴染以外のメンバーのみリロール可能（上限3回）とする。初期影響度は高め（既存の影響度上限88〜89に近い値）に設定するが、「高い影響度＝必ず従うわけではない」という既存ルール（ADR-0003）は変更しない。
4. **探し人**: 探索対象の詳細（名前・関係・特徴）は隠しパラメータとして扱い、道中の「はなす／覚える」を通じて後から判明する方式を採用する。詰みを避けるため、素性由来の固定トピックとして「人を探している→○○（名前）」という断片情報のみキャラクリ時点で開示する。
5. **複合フレーズでたずねる仕組み**: 探し人素性の会話フローから着想を得たものだが、探し人専用にはせず、既存のマンティコア関所型の語順ルール（起点となる単語が文脈を決める既存の話題ディスパッチ仕様）を拡張する汎用フレームとして採用する。覚えた単語同士を組み合わせて尋ねる機能（例：○○＋最後に見た場所）を、他の会話シーン全般にも横展開できるものとして位置づける。

素性一覧および初期化モデル（CharacterBuild）はADR-0023の2軸分離を経て実装・検証完了したため、Statusを`Accepted`とする。
