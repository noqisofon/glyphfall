# ADR-0025: 難易度設定を「世界観プリセット」として再解釈する二層構造の採用

- Status: Proposed
- Date: 2026-09-18

## Background

ADR-0005 において、初期パーティのランダム性（ヤンデレ率・遊び人率など）そのものを「仲間運」という
難易度設定（Very Hard等）としてプレイヤーに選ばせる、という発想と、「苦難の乙女」特徴を持つ幼馴染が
定期的に攫われる創発的な挙動（V1.04ミームなど）をゲームの味として肯定する、という2つの方針が
既に存在していた。

しかしこの時点では「仲間運」という1軸のみが難易度化されており、他の要素（旅の快適さ、情報の得やすさ、
治安など）は難易度という概念と結び付けられていなかった。また、一般的な「イージー／ノーマル／ハード」
という無機質な数値調整ラベルには、イージーモードを選ぶこと自体への心理的抵抗（後ろめたさ）が
つきまとうという課題があった。

## Circumstances

「仲間運」の難易度化という前例を一般化できないかを検討した結果、以下の論点が挙がった。

1. **他にも難易度化しうる要素が複数ある**: 識字率（会話・標識の読みやすさ）、治安（襲撃・盗難の
   発生率）、インフラ整備度（ADR-0004の旅シミュレーションにおける移動手段の摩耗しやすさ）、
   情報開示レベル（ヒントの親切さ）、苦難の乙女発生率（ADR-0005・ADR-0013で言及される突発イベントの
   重み）など、複数の軸が「仲間運」と同列に難易度化候補として存在する。
2. **単純な強弱グラデーションでは表現力が不足する**: 全軸を同じ方向に強めた「イージー」「ハード」の
   2点だけでは、「識字率も治安も高いが仲間運は低い」といった非対称な世界観（神権都市のような）を
   表現できない。
3. **既存のジョーク的挙動の説明**: 「V1.04幼馴染誘拐祭りバージョン」「仲間運Very Hard」といった
   ミーム的ラベルは、単なるバグ・難易度表記ではなく「そういう土地柄・星の下に生まれた世界」という
   物語的な体裁を与えられるはずである。
4. **手軽さとカスタム性の両立**: 軸を増やすほど初見のプレイヤーには決定コストが重くなる。一方で
   個別項目だけ調整したい層（「難しいベースだが識字率だけ上げたい」等）も無視できない。

具体的な検証として、以下6軸を定義し、5つのプリセット（豊かな中央領／辺境の無法地帯／識字ある神権都市／
V1.04幼馴染誘拐祭り版／仲間運Very Hard版）に数値を当てはめる作業を行った。

| 軸 | 単位・スケール |
| :--- | :--- |
| 識字率 | 住民の識字率（0〜100%） |
| 治安 | 旅程1日あたりの襲撃・盗難イベント発生率（%） |
| 馬車耐久度減衰率 | 耐久度100スタート想定で、1日あたりの消費量 |
| 情報開示レベル | 0〜3（0: なし／1: 最小限／2: 標準／3: 親切） |
| 苦難の乙女発生率 | 1章あたりの期待発生回数 |
| 仲間運指数 | 良質な仲間候補が出現する割合（%） |

| 項目 | 豊かな中央領 | 辺境の無法地帯 | 識字ある神権都市 | V1.04幼馴染誘拐祭り版 | 仲間運Very Hard版 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 識字率 | 85% | 25% | 95% | 85% | 25% |
| 治安（襲撃率/日） | 3% | 22% | 5% | 3% | 22% |
| 馬車耐久度減衰/日 | -2 | -8 | -6 | -2 | -8 |
| 情報開示レベル | 3 | 1 | 2 | 3 | 1 |
| 苦難の乙女発生率/章 | 0.3回 | 0.6回 | 0.2回 | 1.0回 | 0.6回 |
| 仲間運指数 | 60% | 35% | 15% | 60% | 5% |

## Rationale

- **難易度ではなく世界観として再解釈する**: 「簡単＝弱者への配慮」という体裁ではなく、
  「統治が行き届いた、情報インフラの整った地方を選んだ」という体裁にすることで、イージー相当の
  プリセットを選ぶことへの心理的抵抗を薄められる。プリセット名も「簡単／普通／難しい」ではなく
  「豊かな中央領」「辺境の無法地帯」のような世界観込みの名前にする。
- **二層構造で手軽さとカスタム性を両立する**: 上位層の「プリセット選択」でワンクリックに全項目を
  一括決定できるようにしつつ、下位層の「詳細設定」で個別項目だけ上書きできるようにする。これにより
  初見プレイヤーの決定コストと、こだわりたい層のカスタム欲求の両方を満たせる。
- **非モノトニックな組み合わせを積極的に含める**: 「識字ある神権都市」のように、識字率・治安は
  高いのに耐久度減衰・仲間運は低い、という非対称なプリセットを用意することで、単純な
  イージー〜ハードの一直線上に収まらない体感の幅を持たせる。
- **既存のジョーク的挙動を「ベースプリセット＋軸オーバーライド」で説明する**: 「V1.04幼馴染誘拐祭り
  バージョン」は中央領相当のベースに苦難の乙女発生率だけを突出させたもの、「仲間運Very Hard版」は
  辺境相当のベースに仲間運指数だけを最低値に固定したものとして表現する。この構造により、
  ミーム的な極端プリセットを個別にハードコードするのではなく、既存の2極（中央領／辺境）からの
  差分として一貫した仕組みで扱える。

## Decision

難易度設定を、無機質な数値調整ではなく「どんな世界に生まれ落ちたか」という世界観プリセットとして
再定義し、以下の二層構造を採用する。

1. **上位層（プリセット選択）**: 識字率・治安・馬車耐久度減衰率・情報開示レベル・苦難の乙女発生率・
   仲間運指数の6軸を一括で決定する、世界観込みの名前を持つプリセットをワンクリックで選択できる
   ようにする。初期プリセットとして「豊かな中央領」「辺境の無法地帯」を2極の基準とし、
   「識字ある神権都市」「V1.04幼馴染誘拐祭り版」「仲間運Very Hard版」を含む最低5種を用意する。
2. **下位層（詳細設定）**: 選択したプリセットをベースに、6軸のうち任意の項目だけ個別に上書きできる
   ようにする。「V1.04幼馴染誘拐祭り版」「仲間運Very Hard版」は、この上書き機構（ベースプリセット＋
   軸オーバーライド）そのものの使用例として位置づけ、専用のハードコードされたプリセットとしては
   実装しない。
3. 6軸の定義とスケール（識字率%、治安＝襲撃率%/日、馬車耐久度減衰/日、情報開示レベル0〜3、
   苦難の乙女発生率＝回/章、仲間運指数%）を本ADRの基準として採用する。Circumstances節の表に
   示した5プリセットの数値を初期値とする。
4. 馬車耐久度減衰率はADR-0004の旅シミュレーションにおける移動手段の消耗、苦難の乙女発生率は
   ADR-0013の突発イベント抽選エンジンにおけるイベント重みとして接続する。接続の実装詳細
   （`SuddenEventDef` の重みへどう反映するか等）は本ADRでは決定せず、実装コミットまたは
   後続ADRに委ねる。

### スコープ外（将来の課題）

- Circumstances節の数値は初期案であり、実プレイでの旅の日数・戦闘頻度との検算による調整を
  必要とする。数値の妥当性検証は本ADRのスコープ外とする。
- 6軸・プリセットの全項目のキー一覧・型・デフォルト値をJSON等の実装可能なスキーマまで詰める作業は、
  本ADRのスコープ外とし、別ADRまたは実装コミットに持ち越す。
- 「プロ値」「目星」「影響度」など既存の隠しパラメータ群と、本ADRで導入する6軸がどう相互作用するか
  （例: 情報開示レベルが目星判定の難度に影響するか等）は未検討であり、将来の課題とする。
