# ADR-0010: 統一見下ろし視点探索システムとダンジョン2Dドット絵化の採用

- Status: Accepted
- Date: 2026-09-14
- Supersedes: [ADR-0008](0008-hybrid-exploration-perspective.md)

## Background

ADR-0008 では、「街・フィールドは見下ろし、ダンジョンは一人称疑似3D」というハイブリッド視点を採用していた。
しかし、ADR-0009 においてグラフィックを「16×16レトロ2Dドット絵／スプライト」へと刷新した結果、仲間たちが1列で追従する見下ろしドット絵のビジュアルと旅情が非常に好評となり、ダンジョンも一人称ではなく同じ見下ろし視点で統一したいという強い要求が生まれた。

## Circumstances

視点方式について、以下の選択肢を再検討した：

1. **当初計画の維持（ダンジョンのみ一人称疑似3D）**:
   - ウィザードリィ風の迷宮感はあるが、ドット絵で愛着の湧いた仲間たち（赤兜のガルツ、道化帽のロロ等）の追従姿がダンジョン内で見えなくなってしまう。
   - 街とダンジョンで描画・操作系が二重になり、保守・開発コストが増大する。
2. **全編統一見下ろしドット絵 ＋ ダイナミックFOV視界制限（本案）**:
   - 街・フィールド・ダンジョンをすべて共通の2Dドット絵見下ろし視点で統一する。
   - 一人称視点のような閉塞感・暗闇の恐怖は、松明の光量に応じた**FOV（視界制限・シャドウマスク）**によって担保する。
   - ダンジョンマップは、初期プロトタイプでは固定マップ（B1F）として実装し、将来的にはDaggerfallのコアである**プロシージャル生成（自動生成ダンジョン）**に対応できるデータ構造とする。

## Rationale

選択肢2（統一見下ろしドット絵）を採用する理由は以下の通り：

1. **冒険体験の一貫性と仲間の存在感**:
   - ダンジョンの薄暗い通路でも仲間たちが後ろをついてくる様子が視覚的に表現され、「パーティで死地に潜っている」という連帯感が劇的に向上する。
2. **暗闇とサバイバル感の両立（FOV）**:
   - 松明の火が消えれば周囲2マスしか見えない暗黒世界となるため、見下ろし視点であっても「角を曲がった瞬間に魔物と鉢合わせる」恐怖や緊張感（ローグライクやDiablo的な面白さ）が十二分に再現される。
3. **シームレスなフロア遷移**:
   - 階段を踏むだけで「街（拠点）」↔「地下迷宮（探索地）」が同一のエンジン上で滑らかに切り替わり、RPGとしてのゲームサイクルが完成する。
4. **プロシージャル生成への拡張性**:
   - 2Dタイルグリッドは、将来的なプロシージャル迷宮生成（部屋と通路の自動接続、宝箱や罠のランダム配置）との親和性が極めて高い。

## Decision

ADR-0008 を改訂し、本作の移動・探索システムとして**「統一見下ろし視点探索システム（街・ダンジョン共通の2Dドット絵 ＋ FOV松明視界）」**を採用する。
ダンジョンは地下岩壁、ひび割れ石床、鉄格子扉、宝箱、昇降階段、魔物シンボルのドット絵タイルによって表現する。
ダンジョン構造は将来的なプロシージャル生成への拡張を前提としつつ、第一歩としてB1Fフロアを実装する。
