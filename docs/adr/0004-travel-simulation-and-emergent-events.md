# ADR-0004: 旅シミュレーション型ファストトラベルと創発イベント

- Status: Accepted
- Date: 2026-09-13

## Background

オープンワールドや広大なマップを持つRPGにおいて、ファストトラベル（FT）は移動の退屈さを解消するための必須機能となっている。
しかし、一般的な「瞬間移動型」のFTを導入すると、移動にかかる時間・危険・宿の確保といったサバイバル要素が形骸化し、世界が単なる「ワープポイントの集合体」に縮退してしまう。
町は攻略に関係ない店が多数あるほど広大であり、町と町の間を移動すること自体に冒険の密度を持たせる必要がある。

## Circumstances

『Daggerfall』のファストトラベル設計を参照し、FTを単なるワープではなく「旅の計画と結果のシミュレーション」として再定義することを検討した。
プレイヤーに移動手段（徒歩／乗り合い馬車／遍歴商人のキャラバンへの便乗）や宿泊（野宿／宿屋の各クラス）を選択させるにあたり、移動中の行動指針（姿勢）をどう設計するかが論点となった。

## Rationale

単に「安全に移動する」だけでは、最適解（最も安全でお金の許す限り良い宿を選ぶ）が固定化してしまう。
プレイヤーが自発的にリスクを取る理由を生み出すため、ファストトラベル中の「姿勢」選択に明確なトレードオフを設けた：

| 姿勢 | 移動時間 | エンカウント率 |
| :--- | :--- | :--- |
| **慎重に** | 変化なし | 低 |
| **普通に** | 基準 | 基準 |
| **大胆に** | 短縮 | 高 |

「大胆に」を選ぶことで移動時間を短縮できるが、そのぶん危険なエンカウント率が跳ね上がる。
この仕組みにより、以下の創発的なプレイが成立する：
- 時間制限付きクエストや病気・毒の治療のためにリスクを承知で「大胆に」急行する。
- ひとり旅でFTを繰り返し、高い遭遇率を逆手に取って狙った加入可能キャラを高速厳選する（ただし山賊やクマに殺されるリスクも比例して跳ね上がる）。

さらに、道中の突発イベントとして以下を組み込む：
- 山賊・強盗との遭遇（戦闘 or 交渉）
- クマなど野生動物との遭遇
- 仲間になる可能性のあるキャラとの遭遇（一期一会の緊張感）
- 行き倒れの旅人（助けるか見殺しにするか選択、話せればクエスト引き継ぎ可能）
- 検問・天候急変

## Decision

ファストトラベルは瞬間移動ではなく、「移動手段 × 宿泊形態 × 移動姿勢（慎重／普通／大胆）」の選択による旅シミュレーションとして実装する。
道中に突発イベントパイプラインを配置し、リスクを取ることで時間短縮や厳選効率を高められるトレードオフ構造を採用する。
