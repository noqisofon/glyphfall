# ADR-0001: Daggerfall × DQ ハイブリッドゲームデザインの採用

- Status: Accepted
- Date: 2026-09-13

## Background

『ドラゴンクエスト』に代表される古典的JRPGは、親しみやすい世界観、記号化されたコマンドUI、直感的な成長曲線を持つ一方で、ストーリーテリングは一本道であり、プレイヤーの行動は作家の用意したレールの内側に制限されている。
一方、『The Elder Scrolls II: Daggerfall』に代表されるクラシックcRPGは、広大無辺な世界、過剰な環境シミュレーション、高い自由度と創発的ナラティブ（システム同士の掛け算によってプレイヤー固有の体験が生まれる構造）を持つが、UIの煩雑さや認知的負荷が極めて高く、参入障壁が高い。

すでに「FF + Wizardry」をルーツとするフォロワー作品（世界樹の迷宮など）は広く認知されているが、その逆方向である「DQ + Daggerfall」というコンセプトのゲームはほぼ存在していない。

## Circumstances

「めんどくさいけど自由度が半端なく高いドラクエを作りたい」という構想が立ち上がった。
しかし、単にドラクエの世界観にcRPGの要素を無秩序に放り込むだけでは、ドラクエの良さであるテンポや親しみやすさが死に、単に「不親切で遊びにくいクローン」に堕ちる危険があった。

シミュレーションの過剰な濃度と、JRPGの親しみやすさをどのように調和させ、一本の筋が通ったシステムとして成立させるかが問われた。

## Rationale

ドラクエの「記号的な親しみやすさ（コマンド選択、親しみやすい呪文やアイテム、枠線UI）」をフロント（外層）に置くことで、Daggerfall的な過剰シミュレーションがもたらす認知負荷を中和できると判断した。

重要なのは単発のネタやイベントの寄せ集めにするのではなく、「システムがシステムを生む」エマージェント（創発的）な連鎖構造を徹底することである：
- 移動の姿勢選択 → エンカウント率 → 突発イベント → 仲間との遭遇 → 影響度 → 隠しパラメータ → 見抜くスキル → 幼馴染の実用ビルド → コミュニティのミーム

すべての要素が一本の因果関係で繋がっていることで、プレイヤーは「DQの皮を被った底なしのシミュレーション」を直感的に楽しみ、自分だけのドラマを語り合えるようになる。

## Decision

表層（UI・記号体系）にドラクエ的フォーマットを採用し、深層（世界生成・環境シミュレーション・NPC心理モデル）にDaggerfall的高密度シミュレーションを採用したハイブリッドゲームデザインを採用する。
独立したルール同士の掛け合わせから偶発的なドラマが生まれるエマージェント・ゲームプレイを設計の根本方針とする。
