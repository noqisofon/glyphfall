# ADR-0008: ハイブリッド移動視点システム（視界制限付き見下ろし × 一人称疑似3D）の採用

- Status: Superseded by [ADR-0010](0010-unified-top-down-exploration.md)
- Date: 2026-09-13

## Background

本作『Glyphfall』は、「Daggerfall × ドラクエ」の融合を標榜し、等幅フォントと罫線文字・ASCII記号によるピュア・グリフ表現（ADR-0007）を採用している。
ゲームサイクルの中核となる「移動・探索」において、どのようなカメラ視点・表現方式を採用するかが論点となった。

ドラクエの最大の特徴である「親しみやすさ・仲間の連帯感」と、Daggerfallの最大の特徴である「一人称視点の閉塞感・未知の迷宮に潜る恐怖」という、相反する2つの魅力をどのように調和させるかが課題であった。

## Circumstances

移動・探索の視点表現として、以下の選択肢を比較検討した：

1. **完全トップダウン見下ろし視点（ドラクエ／古典ローグライク路線）**:
   - マップ全体または周囲を上から見下ろす2Dグリッド。
   - 町の構造や商店の配置を把握しやすく、認知負荷が低い。仲間の追従や自律行動（ADR-0003）が視覚的にわかりやすい。
   - 一方で、Daggerfall的な「暗闇を手探りで進む恐怖」「角を曲がる瞬間の緊張感」が薄れがちになる。

2. **完全一人称疑似3D視点（Daggerfall / Wizardry路線）**:
   - 罫線の遠近法（ワイヤーフレーム）で前方の通路・壁を描画するフロントビュー。
   - 圧倒的な没入感があり、既に実装されているモンスターASCIIアート戦闘ビューと画角が100%一致する。
   - 一方で、無数の店が並ぶ広大な町を探索する際に迷子になりやすく、後ろをついてくる仲間の姿が画面上に見えない。

3. **ハイブリッド方式（街・フィールド：視界制限付き見下ろし ＋ ダンジョン：一人称視点）**:
   - 街やフィールドではドラクエ風の見下ろし2Dグリッドをベースとするが、夜間や路地裏・荒野では「視界制限（FOV / 索敵コーン / 松明）」を適用して死角を作る。
   - 危険な洞窟・迷宮（ダンジョン）に足を踏み入れた瞬間、一人称疑似3Dグリフビューへと切り替わる。

## Rationale

検討の結果、選択肢3（ハイブリッド方式）を採用するのが最も本作のゲームデザインに合致し、かつ強烈なプレイ体験を生み出せると判断した。

判断の理由は以下の通り：

1. **「日常（DQ）」と「非日常・死の危険（Daggerfall）」の劇的なコントラスト**:
   安全な生活圏・拠点である町では、ドラクエらしい親しみやすさで見通しよく探索・買い物を楽しむことができる。
   一方、一歩ダンジョンの階段を降りた瞬間、視界が一人称の閉塞的な暗闇に切り替わることで、「生きて生還できるかわからない領域に踏み込んだ」という心理的落差と緊張感を最大化できる。

2. **仲間の自律行動と存在感の視覚化（街・フィールド）**:
   ADR-0003で定めた「隠しパラメータ影響度による仲間の自律行動（勝手についてくる、勝手に店に寄り道する、勝手に会話に割り込む）」は、見下ろし視点だからこそ画面上でダイレクトに視覚化され、プレイヤーに愛着やもどかしさを感じさせることができる。

3. **見下ろし視点への視界制限（FOV）によるDaggerfallイズムの注入**:
   単なる全知の見下ろしではなく、主人公の向きや松明の光量に応じた視野（Line of Sight / FOV）を適用することで、「角を曲がるまで何がいるかわからない」「夜の路地裏で辻斬りや山賊に背後を取られる」といったDaggerfallらしい油断のならなさを両立できる。

4. **戦闘画面とのシームレスな一体感（ダンジョン）**:
   ダンジョン内の一人称疑似3Dグリフビューは、中央ウィンドウのモンスターASCIIアート戦闘ビューと画角・スケール感が完全に一致するため、エンカウントから戦闘突入、戦闘終了後の探索復帰が極めて自然に流れる。

## Decision

移動・探索システムとして、**「街・フィールド：視界制限付き見下ろし視点」×「ダンジョン：一人称疑似3Dグリフ視点」**のハイブリッド方式を採用する。

- **街・フィールド**:
  - 等幅文字セルによる2Dグリッド見下ろし描画。
  - 主人公とパーティメンバー（追従列）の描画。
  - 時間帯（昼／夜）および光源（松明・ランタン）に応じたFOV（視界制限・シャドウキャスト）の適用。
- **ダンジョン**:
  - 罫線文字（`│ ─ ┌ ┐ / \` 等）の遠近法によるステップ移動式一人称疑似3D描画。
  - モンスターASCIIアート戦闘ビューとの画角共有。
  - オプション／スキルによる罫線ミニマップ（オートマッピング）の併用。
