# ADR-0023: キャラクリ「素性」システムの2軸分離（属性軸 × 旅立ちの動機軸）

- Status: Proposed
- Date: 2026-09-17

## Background

ADR-0022により、Glyphfallのゲーム開始パターンは「素性（出自）システム」として統一され、
商人の息子・傭兵崩れ・元神官見習い・農家の三男坊・駆け落ち者・探し人といった項目を
キャラクリ時に単一のフラットなリストから1つ選ぶ、という形で確定していた。

このリストには、性質の異なる2種類の項目が同じ階層に混在していた。

1. **「どういう人物か」＝属性・出自**
   例：商人の息子、傭兵崩れ、元神官見習い、農家の三男坊
   → 経済・武力・知識・没落／底辺の4系統に分類される、キャラクターの社会的出自・
   職業的背景を表す項目
2. **「当初の旅の目的」＝旅立ちの動機**
   例：駆け落ち者、探し人、お尋ね者、復讐者、冒険者志望
   → なぜ今この瞬間に旅をしているのか、という起点となる状況・感情を表す項目

単一リストのままではこの2種類が排他的な選択肢として扱われてしまい、「農家の三男坊が
駆け落ちして旅に出る」のような、本来は両立しうる組み合わせを表現できない。

## Circumstances

素性一覧のリスト化・深掘りを進める過程で、上記の混在から生じる問題が具体的に見えてきた。

- 「駆け落ち者」と「農家の三男坊」を同時に選べない、という不自然な排他性が生まれる
- 組み合わせの表現力が「リストの項目数」に線形にしか増えず、掛け算的に増えない
- 各素性に付随する初期パラメータ・分岐イベント設計（例：影響度の初期値、話題ウィンドウ
  への固定トピック配置）が、属性起因のものと動機起因のものとで本来別々の設計原理を
  持つにもかかわらず、同一の設計フレームで扱われてしまう

一方、ADR-0022以降の検討メモには、すでに以下の設計判断が「動機」側の項目として蓄積
されていた。

- **駆け落ち者**：初期から二人で始まる。初期影響度が高め（素の人間の上限88〜89近辺）
- **探し人**：一人で始まる。探索対象は非公開でプレイ中に判明。話題ウィンドウに固定
  トピックとして「人を探している→○○」が乗る。人探しを放棄して冒険者稼業に専念しても
  システム上ペナルティなし
- **お尋ね者**：探し人の裏返し（追う側→追われる側）
- **復讐者**：探し人と似た構造だが対象への感情・解決後の展開が異なる（再会 vs 戦闘/対話）
- **冒険者志望**：派閥（冒険者ギルド等）との接続は「初期動機」ではなく「現在の所属・
  実績」で決まるという分離ルールがすでに存在する

これらはいずれも「属性・出自」とは独立に機能する「旅立ちの動機」であり、対処案として
以下の2案を比較した。

### Option A: 2軸分離

属性軸（出自）と動機軸（旅立ちの理由）を独立した選択軸に分離し、キャラクリ画面で
両方を選択させる。

- 表現力：高（組み合わせ数が乗算的に増加）
- 実装複雑度：中（キャラクリUIの選択フローが2ステップになる、初期化ロジックが2系統の
  合成になる）
- 既存メモとの整合性：高（既存の各動機の設計は無改修でそのまま動機軸に移行可能）

### Option B: 単一リストのまま維持（不採用）

現状のADR-0022のリスト構成を維持する。

- 表現力：低（項目数分の選択肢に留まる）
- 実装複雑度：低（現状のまま）
- 既存メモとの整合性：低（「駆け落ち者」と「農家の三男坊」の排他性など、すでに
  指摘された矛盾が残る）

## Rationale

最大の論点は「UI選択ステップの増加」と「表現力の増加」のトレードオフだった。

本プロジェクト全体の設計思想（隠しパラメータ思想＝ADR-0003・ADR-0022、覚えるシステム
による能動的情報収集＝ADR-0002・ADR-0012、素性の初期動機と実際のプレイ内容の乖離を
許容する方針＝ADR-0022の探し人設計）はいずれも「プレイヤーに一手間かけさせることで
自由度と没入感を担保する」という一貫した哲学を持っている。キャラクリの選択ステップが
1つ増えること自体は、このプロジェクトのコンセプト（「めんどくさいけど自由度が半端なく
高い」）と親和性が高い。したがってOption Aの複雑度増加はデメリットというより、
コンセプトへの適合として許容できると判断した。

また、Option Bのまま項目を増やし続けると、選択肢が増えるたびに排他性の矛盾（属性由来の
項目と動機由来の項目の衝突）が蓄積し、収拾がつかなくなることが見えていた。この矛盾は
今すぐ実害が小さくても、素性の種類が増えるほど指数的に扱いにくくなるため、早期に構造を
分離しておく方が長期的なコストが低いと判断した。

## Decision

1. 素性システムを、以下の2つの直交する選択軸に分離する。
   - **属性軸（出自）**：経済・武力・知識・没落／底辺の4系統からなる、キャラクターの
     社会的出自・職業的背景
   - **動機軸（旅立ちの理由）**：駆け落ち者・探し人・お尋ね者・復讐者・冒険者志望
     などの、旅立ちの起点となる状況・感情
2. キャラクリ画面では両軸を独立に選択可能とし、自由な掛け合わせ（例：「元神官見習い」×
   「復讐者」、「商人の息子」×「お尋ね者」）を許容する。
3. 各軸が担う役割を以下のように切り分ける。

   | 軸 | 主な役割 |
   |---|---|
   | 属性軸 | 初期スキル・初期習熟度、初期資金・装備、出身地域との縁 |
   | 動機軸 | 初期パーティ構成（同行者の有無）、初期影響度の補正、話題ウィンドウの固定トピック、派閥との初期関係性 |

4. ADR-0022で定めた各動機項目（駆け落ち者・探し人）の設計（プール制の駆け落ち相手選択、
   探し人の後から判明方式、複合フレーズでたずねる仕組み）は無改修のまま動機軸に移行する。
5. 派閥システムとの接続ルール（「現在の所属・実績」で判定し、動機軸の初期値では判定
   しない、ADR-0022で示唆済み）を、動機軸の役割として明文化する。
6. 「素性」という呼称は、属性軸と動機軸の両方を包含する上位概念として扱う。

以下は本ADRの範囲外の残課題であり、別途検討する。

- 属性軸の系統一覧（経済・武力・知識・没落／底辺）と、既存項目（商人の息子、傭兵崩れ、
  元神官見習い、農家の三男坊等）の棚卸し・確定
- 動機軸の項目一覧（駆け落ち者・探し人・お尋ね者・復讐者・冒険者志望、および今後
  追加しうる候補）の確定
- 明らかに矛盾する組み合わせ（あれば）の扱い方針
- キャラクリUIのフロー設計（2段階選択の画面構成）
- 動機軸各項目の初期化ロジックのインターフェース設計（初期パーティ／初期影響度補正／
  話題ウィンドウ固定トピック／派閥初期関係性、の4種の効果を持ちうる共通構造）

素性の系統一覧・項目一覧はまだ確定しておらず、UIフロー設計も未着手のため、Statusは
`Proposed`とする。
